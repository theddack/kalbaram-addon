## 0. 목적과 지키는 선

상대 정보를 **표시·문구 수준이 아니라 실제 계산에 반영**한다. 다만 기존 개발 목적은 그대로 둔다.

- 증강 중심의 재미있는 빌드 · 비정석 빌드와 증강 시너지 존중 · 초보자가 이해할 수 있는 추천
- 정석 빌드 강제 금지 · 특정 아이템 순위 강제 금지
- **상대 대응을 이유로 전 챔피언 빌드가 방어 아이템으로 수렴하지 않게 한다**

## 3. P4-4 구현 때의 검증 계획 (기획서 7장)

승인 뒤에 쓸 계획이다. 지금은 하지 않았다.

- **실제 게임 기록** — 보유한 5판 전체. 변경된 사례와 변경되지 않은 사례를 모두 적는다.
- **상대 조건 변경 테스트** — 챔피언·증강·보유 아이템은 고정하고 상대 조건만 ↑↓ 양방향으로. 10가지 축(피해 유형 · 방어력 · 마저 · 체력 · 회복량 · 보호막량 · 평타 의존도 · 군중 제어 · 폭딜↔지속 · 혼합 구성). **순위가 반드시 바뀌어야 한다는 조건은 만들지 않는다** — 대응 효과의 기여도가 합리적으로 변하는지만 본다.
- **전체 챔피언 173명** — 증강 없음 / 단일 / 복수. 복수 증강은 전수 계산하지 않고 실제 기록·충돌 가능성 높은 조합·유형 전환 조합으로 범위를 정하고 근거를 적는다.
- **회귀** — Phase 3 결과를 새 비교 기준으로 동결하되 v0.1.94 기준선도 남긴다. 기준선 263장면 · 전체 자동 테스트 · Top1/3/6 · 빌드 구성 · 증강 등급 · 비정석 빌드 유지 · 캐시↔초기화 일치.
- **성능** — Phase 3 결과를 기준으로. 다음 구매·증강 추천·빌드 3종 시간, 캐시 적중률, 게임 연동 재계산 횟수(`tools/heal_churn.js`), 계산 비용이 큰 사례 포함. **실제 플레이로 확인하지 않은 값을 실제 플레이 성능으로 적지 않는다.**
- Phase 4 의 상대 조건 장면은 Phase 6 회귀 기준선 확장에 그대로 쓸 수 있게 보존한다.

## 4. 개발 제한 사항 (기획서 9장 그대로)

- 특정 아이템 순위를 목표로 계수를 조정하지 않는다
- 기존 증강 시너지·비정석 빌드를 임의로 제거하지 않는다
- 원본에 없는 수치를 임의로 만들지 않는다
- 상대 대응을 이유로 방어 아이템을 강제하지 않는다
- 테스트를 통과시키려고 검증 조건을 완화하지 않는다
- 계산 모델의 한계를 가중치 추가로 덮지 않는다
- 실제 기록으로 확인할 수 있는 것을 미확인으로 남기지 않는다
- 조사 범위 밖의 UI 개편·구조 리팩터링을 하지 않는다
- 승인 전 main 병합·태그·릴리스를 하지 않는다
