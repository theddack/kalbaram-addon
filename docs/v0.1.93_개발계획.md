# v0.1.93 개발 계획

기준: v0.1.92 태그(`40e950a`) · 브랜치 `feat/v0193-ally-support` · 릴리스·태그·배포는 별도 승인 전까지 하지 않아요.

목표: 증강으로 새 플레이 방식을 찾되 실제로 쓸 수 있는 추천. 당분간 계산 엔진의 기능 완성도를 높여요.

## 의존 관계

```
P1 아군 지원 효과 계산 ──▶ P2 서포터 평가 척도 ──▶ P3 태그 중복 제거
        │                                          ▲
        └──────────────▶ P4 남은 계산 기능 ─────────┘ (계산되는 효과가 늘수록 태그에서 뺄 몫이 늘어남)
                                   │
                                   ▼
                         P5 독특한 빌드 발굴 (P1~P4 의 계산 위에서 설명·불확실성 표시)
```

- **P2는 P1 뒤에.** 서포터의 아군 강화가 계산에 없는 상태에서 척도를 바꾸면, 빠진 몫을 척도로 메우게 돼요.
- **P3는 P2 뒤에.** v0.1.92 실험(TAG_DEDUP=effect)에서 태그만 빼면 서포터 아이템이 크게 줄었어요(서포터 장면 몰빵 307 → 166). 태그가 척도 문제를 가리고 있었기 때문이에요.
- **P4는 P3와 맞물려요.** 효과를 새로 계산하면 그 효과의 태그는 중복이 돼요. P3의 '계산됨' 판정(tools/tag_overlap.js)이 자동으로 따라가게 해요.
- **P5는 마지막.** 계산이 비어 있는 효과가 많을수록 '독특한 빌드'가 계산 누락의 결과일 수 있어요.

## 단계별 범위

| 단계 | 할 일 | 끝났다고 보는 기준 |
|---|---|---|
| P1 | 아군 공격 속도·공격력·적중 시 피해·피해량, 아이템 아군 버프를 기준 아군 모델로 계산. 이미 서포터 자기 피해로 세던 아군 몫(나미 E 등)은 옮김 | 단위 테스트, 서포터 추천·몰빵/균형 회귀, 계산 시간 |
| P2 | 공격 지표 ↔ 지원 지표 비교 구조 분석, 바닥값(콤보 300·지원 600) 영향, P1 전후 비교. 서포터 아이템 강제 없음 | 서포터 장면에서 공격형 아이템이 '맨몸 콤보가 작아서' 고평가되는지 수치로 확인·개선 |
| P3 | 태그 역할 분리(능력치 선호 · 플레이 스타일 · 미계산 효과). 계산된 효과의 태그는 수치와 중복 보상하지 않음 | 목표 함수 왜곡 감소, 서포터 추천 악화 없음 |
| P4 | 미계산 효과를 추천 영향도순으로: 적중 시·반복 발동, 체력 조건, 사용 효과, 상처·보호막 감소, 이동 속도·유틸, 상호작용 | 검증표 '계산되지 않음' 감소, 지표로 못 쓰는 효과는 공통 구조 설계 먼저 |
| P5 | 몰빵이 균형과 다른 이유 설명(증강 몫 증가 vs 전투 가치 손실), 근거 부족 조합은 불확실성 표시 | 도구·화면에 이유와 불확실성이 나옴 |

## P1 설계: 기준 아군 모델

**게임 데이터로 확인되는 것 (설명 수치)**

| 출처 | 효과 | 18레벨 값 |
|---|---|---|
| 룰루 W 변덕쟁이 | 아군 공격 속도 | 30%, 4초 |
| 잔나 E 폭풍의 눈 | 아군 공격력 | 30 + 주문력 10%, 4초 |
| 레나타 W 긴급 구제 | 아군 공격 속도 | 30% → 5초에 걸쳐 60% |
| 유미 E 슈우우웅 | 아군 공격 속도 | 35% + 주문력 8%, 3초 |
| 나미 E 파도 소환사의 축복 | 아군 기본 공격·스킬 3회 추가 마법 피해 | 80 + 주문력 20%, 6초 |
| 소나 Q 용맹의 찬가 | 아군 다음 기본 공격 추가 마법 피해 | 30 + 주문력 10% |
| 아이번 W 수풀 가꾸기 | 아군 기본 공격 추가 마법 피해 | 30 + 주문력 10%, 1.5초 |
| 불타는 향로 축성 | 아군 공격 속도 25%·적중 시 마법 피해 20 | 6초 |
| 흐르는 물의 지팡이 급류 | 아군 주문력 40·스킬 가속 15 | 6초 |

**계산을 위해 정한 가정 (실게임 검증 필요)**

1. **기준 아군 = 원거리 딜러 균형 빌드(증강 없음) 29명의 18레벨 중앙값.** 평타 초당 피해 891, 공격 속도 2.04, 공격력 324, 스킬 초당 피해 86, 스킬 가속 10, 공속 계수 0.656. `tools/ally_model.js`로 다시 잴 수 있어요. 기준 상대(`TARGET`)를 정한 방식과 같아요.
2. **아군 강화 1번 = 서포터 기술 1번.** 보호막·회복을 콤보 1번에 1번 세는 지금 기준과 같아요. 지속시간 동안 기준 아군이 더 넣는 피해를 세요.
3. **아군이 더 넣는 피해 1 = 지원 1 (체력 단위).** 한타는 양쪽 체력 차이로 갈리므로, 적 체력 1을 더 깎는 것과 아군 체력 1을 지키는 것을 같게 봐요. 지원 지표에 더해요.
4. **받는 아군은 1명.** 지금 회복·보호막 계산과 같아요. 여러 아군에게 주는 효과는 `ALLY_TARGETS` 하나로 바꿀 수 있게 하고, 근거가 없어 1로 둬요(2명일 때의 민감도는 보고).
5. **기준 아군의 주문력 계수는 0으로 봐요** (원딜). 흐르는 물의 지팡이의 아군 주문력은 메이지 아군이면 커지지만, 기준 아군에선 0이에요.

**중복 확인**: 나미 E·소나 Q 적중 피해·아이번 W 아군 피해는 지금 서포터 자기 콤보에 1번씩 들어가 있어요. 아군이 넣는 피해라 콤보에서 빼고 아군 모델로 옮겨요(같은 효과를 두 번 세지 않게).
