## 0. 먼저 볼 것 (미검증·미해결)

1. **실제 게임 검증은 하나도 하지 않았다.** 아래 '자동 검증 완료'는 계산·화면 테스트(맥·GitHub CI)까지다. 외부 테스터 재검증(기획서 9.4)과 Windows 실게임 성능(11.2)은 남아 있다.
2. 실게임 확인 대기: 미구현 P0 11개(`docs/미구현_분류.md`), 지옥불 난사 발동 '10회 사격'(1회만 셈), 치명적 미사일 원본 Cooldown 4(안 넣음), 민감도 높은 가정(탱크 엔진 등, `docs/가정값_목록.md`).
3. **리치베인 과대평가 의심**: 공식 추천과 다른 27명 중 16명이 우리 1위가 리치베인 (서포터 5명 포함, `docs/공식_추천_차이.md`). 점수는 고치지 않았다 — 후속 확인.
4. 설명 '?' 7개 증강: 퀘스트 6개 `QuestRequirement`(증강 스펠에 값 없음), 도취(이름 모를 계산식 부품). 원본 확인 불가로 남김.
