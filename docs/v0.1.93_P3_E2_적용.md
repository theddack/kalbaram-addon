# v0.1.93 P3 E2 적용 — 회복·보호막 특성 규칙 통일

승인안 E2를 데이터 생성 단계에 넣었어요. 분석은 [v0.1.93_P3_분석.md](v0.1.93_P3_분석.md)에 있어요. 결과는 계산끼리 비교한 것이고, 실제 게임에서는 확인하지 않았어요.

## 미검증·새로 드러난 문제 (먼저)

- **실게임 미검증:** P1·P2 가정 위에 있어요.
- **회복·보호막 증강의 몰빵 추종이 약해졌어요 (11 + 3 + 1장면):** 럭스·애니·소나가 회복·보호막을 키우는 증강을 골랐을 때 생겨요. 몰빵이 서포터 아이템 대신 피해 아이템을 골라요.

| 장면 | 몰빵 증강 몫 (E2 전 → 후) | 전투 가치 몰빵 ÷ 균형 (전 → 후) |
|---|---|---|
| 럭스 + 응급처치 키트 | 33.5 → 15.7 | 0.98 → 1.03 |
| 애니 + 응급처치 키트 | 32.7 → 15.3 | 0.92 → 1.05 |
| 소나 + 격려하기 | 12.8 → 6.6 | 1.20 → 1.13 |

- **이 문제의 원인:** E2 전 빌드는 전투 가치 손실이 허용 범위 안이었는데도, E2 뒤 몰빵은 증강 몫이 작은 빌드를 골랐어요.
  - 몰빵이 회복·보호막 증강을 쫓는 힘의 상당 부분이 수치(증강 몫)가 아니라 **회복·보호막 태그 가중치**에서 나왔다는 뜻이에요.
  - E2가 근거 없던 1.0 고정을 없애자 드러났어요.
  - 이건 몰빵 목표 함수(증강 몫의 세기)의 문제라, 승인 없이 바꾸지 않았어요. 아래 'P3에 남은 작업'에 넣었어요.
- **점검표 잣대는 같아요:** 그래서 E2 전후 점검표 숫자는 바로 비교할 수 있어요.

## 1. 바꾼 것

- **데이터 생성 (`build_data.py`):**
  - `allysupport` 회복·보호막 특성 **1.0 고정을 없앴어요.**
  - 대신 `ally_healshield_trait`(지원 수치가 나오는 스킬·패시브·규칙 효과 수 × 0.4, 최대 1)를 써요. 다른 특성과 같은 규칙이에요.
  - 스킬·패시브·규칙 효과가 모두 붙은 뒤에 세요.
- **데이터 변화:** 생성 시각과 아군 지원 28명의 회복·보호막 특성만 바뀌었어요.
  - **0:** 닐라·루시안·헤카림.
  - **0.4:** 럭스·흐웨이·쓰레쉬·멜·세라핀·오리아나·애니·갈리오·리 신·모르가나·바드·알리스타·질리언·케일·크산테·클레드.
  - **0.8:** 나미·세나·소나·쉔·아이번·카르마·킨드레드·탐 켄치·피오라.
  - **1.0 그대로:** 소라카·잔나·룰루·타릭·밀리오·유미·레나타·라칸.
- **확인한 것:**
  - 데이터 값이 엔진 계산으로 센 값(`tools/exp_env.js healShieldTrait`)과 36명 모두 같아요. 처음엔 킨드레드·피오라 2명이 달랐어요. 레벨 비례값(`lvl`)만 있는 효과를 빠뜨려서였고, 고친 뒤 같아요.
  - 실험 E2(`HS_TRAIT=computed`)와 균형 빌드 173명, 점검표 3,038장면이 모두 같아요.
- **실험 설정:**
  - `HS_TRAIT=computed`는 기본이 됐어요. 비교용으로 `HS_TRAIT=fixed`(예전 1.0 고정)를 남겼어요. 이 설정의 결과는 적용 전과 173명 모두 같아요.
  - E3(`TAG_DEDUP=unique`)은 실험 설정 그대로예요.
- **테스트:**
  - 파이썬 `AllyHealShieldTrait`: 세는 규칙, 그리고 데이터에 1.0 고정이 없는지.
  - `tests/scale.test.js`: 데이터와 엔진 계산이 같은지(36명).
  - 럭스·소나 향로 장면: 풀린 2장면은 일반 테스트로 옮겼어요. 남은 3장면은 todo예요.
- **기준선:** E2 전(C)은 `tests/data/p2/*_C`에 그대로 있어요. E2 후는 `tests/data/rec_baseline.json`과 `tests/data/p3/*_E2`예요.

## 3. P3에 남은 작업

1. **몰빵이 회복·보호막 증강을 쫓는 힘 (새로 드러남, 위):**
   - 태그 대신 수치(증강 몫)로 충분히 쫓는지 원인을 나눠 볼게요. 확인할 것은 세 가지예요: 증강 출력 가중치, focus 세기, 전투 가치 허용폭.
   - 목표 함수 변경이라 분석과 대안을 먼저 보고할게요.
2. **E3 (`TAG_DEDUP=unique`):**
   - 계산되는 고유 효과 태그를 빼는 안은 실험 설정으로 두고 있어요.
   - 미계산 효과(슈렐리아 아군 이동 속도 등)가 상대적으로 유리해지는 비대칭이 있어요. 그래서 P4에서 그 효과를 계산한 뒤 다시 잴게요.
3. **Riot 역할 기본값 (서포터 → 회복·보호막 1.0):**
   - 럭스는 E2 뒤에도 회복·보호막 가중치가 1.16이에요(역할 1.0 + 특성 0.4 × 0.4).
   - 바꿀지는 근거 자료(역할 태그와 실제 지원 몫)를 먼저 정리해서 보고할게요.
4. **`allysupport` 분류 오탐 (닐라·루시안·헤카림):**
   - 특성은 0이 됐지만 분류는 남아 있어요. 그래서 P2 같은 분모(C)와 서포터 아이템 버프 조건이 계속 적용돼요.
   - 셋 다 맨몸 지원이 0이라 같은 분모의 실제 영향은 없어요. 서포터 아이템 버프 조건은 따로 확인이 필요해요.
5. **공식·연계 가산 비중 (서포터 점수의 26~45%):** 태그 중복은 아니지만 수치보다 큰 경우가 있어요. 범위 밖이라 기록만 해요.

## 4. P4로 넘기는 작업

1. **자기 보호막과 아군 보호막이 섞이는 문제:**
   - 지원 지표(`shield`·`heal`)가 자기용과 아군용을 나누지 않아요.
   - 갈리오(W 자기 보호막 451을 아군 지원으로 셈, R의 아군 몫은 미계산)와 쉔(R 아군 + 패시브 자기)이 대표 사례예요.
   - 계산 구조에서 대상(자기·아군)을 나눠야 해요.
2. **아군 강화를 지속시간 전부로 세는 P1 가정 2 (과대평가 가능성):**
   - 불타는 향로의 아군 몫 580을 회복·보호막 양과 상관없이 6초 전부 세요.
   - 럭스·소나 향로 역행 남은 3장면(todo)의 원인 후보예요.
3. **미계산 아군 효과:**
   - 아군 이동 속도(슈렐리아·룰루 W·카르마 E 등), 아군 방어력(오리아나 E), 부활·무적(질리언 R).
   - E3을 다시 재기 전 선행 작업이에요.
4. **계획서의 P4 항목:** 적중 시·반복 발동, 체력 조건, 사용 효과, 상처·보호막 감소, 이동 속도·유틸, 상호작용.
