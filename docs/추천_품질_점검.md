# 추천 품질 점검 (계산 일관성)

> 이 문서의 숫자는 **계산끼리 앞뒤가 맞는지** 본 것이에요. 실제 게임에서 추천이 맞았는지(정확도)가 아니에요.
> 실제 게임 대조는 게임 기록이 모이면 따로 해요.

다시 만들기: `node tools/augment_quality.js` (대표 챔피언 12명 × 증강 전부, 약 2분)

## 판정 기준

| 대상 | 통과 조건 |
|---|---|
| 아이템 업그레이드 증강 | 후보 아이템 중 하나가 몰빵 빌드에 있음 |
| 숫자로 계산되는 증강 | 몰빵 빌드에서 증강이 보태는 가치 ≥ 평소(균형) 빌드에서 보태는 가치 |
| 효과 종류만 있는 증강 | 주된 효과 종류(강도 0.6 이상)를 가진 아이템이 1개 이상 |
| 변칙 | 받쳐 주는 증강이 있으면 뒤집힌 쪽 아이템 2개 이상, 없으면 받쳐 주는 정도 0 (🧪 실험 빌드) |

## 결과 (2026-10-20)

```
증강 몰빵: 1972/2009 살림 (98.2%) · 균형 대비 평균 1.2개 바뀜
변칙: 79/79 정상 (100.0%)
못 살린 원인: 한계-회복 15 · 작은 차이 14 · 확인 필요 8
(챔피언 전투 특성 보정 뒤: 베인 은화살로 공격 속도 가치가 커져 베인 몰빵 빌드 6개가 '작은 차이'로 바뀜. 보정 전 1978/2009)
```

## 실패 원인

| 원인 | 뜻 | 조치 |
|---|---|---|
| 한계-회복 | 회복·보호막만 키우는 증강(대지의 영혼·바다의 영혼·우리의 치유·자비의 일격)을 회복 스킬 없는 챔피언이 고름 | 살릴 아이템이 없는 게 맞아요. 수정하지 않음 |
| 작은 차이 | 몰빵이 평소보다 증강 가치를 덜 살리지만 차이가 10% 미만 | 몰빵은 빌드 전체 가치도 같이 봐서 생기는 차이. 수정하지 않음 |
| 확인 필요 | 그 밖 | 아래 목록. 몰빵 빌드가 쓰는 지표 가중치와 이 점검이 쓰는 가중치(균형 기준)가 달라서일 가능성이 커요. 실제 게임 기록으로 다시 볼 것 |

v0.1.22에서 고친 것: '메아리 시전'에 '주문력' 태그가 붙어 있었어요(스킬을 한 번 더 쓰는 효과라 물리 스킬도 두 배). 스킬 가속으로 바꿔 실패 6개가 없어졌어요.
