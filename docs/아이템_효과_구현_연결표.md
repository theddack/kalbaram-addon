# 아이템 효과 구현 연결표 — 상대 대응

게임 데이터 `16.22.1` · 만든 도구: `node tools/counter_audit.js --write`

> 전체 아이템(전설 + 신발 114개)의 **원본 설명**에서 상대 대응 효과를 찾아, 그 효과가 추천 계산에 들어가는지와
> 들어간다면 **상대 정보를 실제로 보는지**를 가른 표예요. 계산·데이터끼리의 대조이고 실게임 결과가 아니에요.

### 이 표가 보는 범위 (2026-11-25 보탬)

- 이 표는 **상대 대응 효과만** 본다. 아이템의 **모든 고유 효과**가 계산되는지는 `docs/아이템_검증표.md` 쪽이고,
  원본 설명과 수치까지 전부 대조하는 일은 **Phase 5A(`tools/item_source_audit.js`)** 로 따로 잡혀 있다 (아직 안 함).
- '상태' 칸의 **능력치로 계산**은 관통력처럼 능력치 칸의 값으로만 들어간다는 뜻이고, **수치 계산**은 조건부 고유 효과를
  따로 센 것이다. 둘을 같은 '계산됨'으로 묶지 않는다.
- 아래 표는 **정규식이 원본 설명에서 찾은 것**이라, 사람이 원본을 읽고 뺀 것은 각 절 끝 '뺀 것'에 이유와 함께 남긴다.
- **'능력치로만 계산'의 한계 (2026-11-25 보탬)**: 이동 속도처럼 **기본 능력치 칸과 조건부 고유 효과가 같은 이름**인 항목은
  이 표가 둘을 가르지 못한다. 예를 들어 칠흑의 양날 도끼의 `MS 15` 는 기본 능력치가 아니라
  **'물리 피해 뒤 2초 +20' 을 가동률 75% 로 환산한 값**(`passiveStats`)인데 표에는 그냥 `MS` 로 보인다.
  그 환산이 맞는지는 아이템마다 원본 조건을 읽어야 알 수 있고, 그 작업이 **Phase 5A** 다.
  (실제로 칠흑은 이 환산이 **다른 패시브**의 조건이라 C9 에서 따로 다룬다 — `docs/v0.1.95_Phase4_C9_저항감소_조사.md`)
