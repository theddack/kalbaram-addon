# v0.1.93 P3 태그 중복 평가 — 분석과 실험 비교 (적용 전 보고)

브랜치 `feat/v0193-ally-support` · 기준: P2 적용(C). **기본 추천은 바꾸지 않았어요.** 모든 변경안은 실험 설정으로만 비교했어요. 결과는 계산끼리 비교한 것이고, 실제 게임에서는 확인하지 않았어요.

## 미검증·주의 (먼저)

- **실게임 미검증:** P1·P2 가정 위에 있어요.
- **E3 단독은 점검표를 돌리지 않았어요:** 빠른 지표만 쟀어요. 점검표 3,038장면은 E2와 E2+E3만 돌렸어요(각 약 9분, 18분).
- **같은 잣대로 비교했어요:** 이번 실험은 점검표 잣대(기준값 C)를 바꾸지 않아요. 그래서 점검표 숫자는 C와 바로 비교할 수 있어요.

## 1. 지금 태그가 하는 일

아이템 점수 = 수치(전투 지표 증가) × 4 + 태그 점수 × 0.4. 태그 점수 = Σ 챔피언 가중치 × 아이템 태그 강도이고, 이미 가진 태그는 줄여서 세요. 공식 추천과 증강 연계 가산도 태그 점수 쪽에 들어가요.

`node tools/tag_share.js`로 균형 빌드 아이템 점수를 나눠 봤어요(C 기준):

| | 수치 | 능력치 태그 | 계산된 효과 태그 | 미계산 효과 태그 | 공식·연계 가산 |
|---|---:|---:|---:|---:|---:|
| 전체 173명 | 66% | 13% | 3% | 1% | 18% |
| 원딜 | 86% | 7% | 1% | 0% | 6% |
| 탱커 | 43% | 25% | 2% | 2% | 28% |
| 아군 지원 36명 | 53% | 14% | 6% | 1% | 26% |
| 소라카 | 26% | 18% | 12% | 0% | 44% |
| 잔나 | 28% | 12% | 14% | 1% | 45% |

- **계산된 효과 태그(중복 보상)는 전체로는 작아요(3%).** 하지만 회복형 서포터에서는 12~14%예요. 주로 월석·헬리아·향로·구원의 회복·보호막(HEALSHIELD) 태그가 이미 지원 지표로 계산되는데도 한 번 더 점수를 받아요.
- **공식·연계 가산이 서포터 점수의 26~45%예요.** 태그 중복은 아니지만, 수치보다 큰 경우가 있다는 걸 기록해 둬요. P3 범위 밖이라 바꾸지 않았어요.

## 2. 태그를 세 역할로 나눴어요

| 역할 | 해당 태그 | 수치와의 관계 | 처리 원칙 |
|---|---|---|---|
| **능력치 선호** | 공격력·주문력·공격 속도·치명타·체력·방어력·마법 저항력·마나·이동 속도, 그리고 **기본 능력치에서 나오는** 관통·가속·흡혈 | 수치에 늘 들어가요. 태그는 '이 챔피언이 어떤 능력치를 좋아하나'를 실어요 | 남겨요 |
| **플레이 스타일** | 역할 기본값(서포터 = 회복·보호막 1.0, 탱커 = 제어 0.6 …), 챔피언 특성(스킬 설명) | 지표 가중치(어떤 지표를 중요하게 보나)로 들어가요 | 실제 계산과 맞는지 확인해요 (`allysupport`, 아래 3) |
| **미계산 효과** | 수치로 계산되지 않는 고유 효과 태그 (`tools/tag_overlap.js` '계산 안 됨') | 태그가 유일한 신호예요 | 남겨요 |
| (중복) **고유 효과로 계산되는 효과 태그** | 예: 월석·헬리아의 HEALSHIELD, 구원의 TRUE | 같은 효과를 수치와 태그로 두 번 세요 | 빼는 안을 실험해요 (E3) |

**v0.1.92 실험 `TAG_DEDUP=effect`(E1)의 문제를 찾았어요.** 관통·가속·흡혈은 '효과 태그'로 분류돼 있어서, 기본 능력치로 계산되는 경우도 '계산됨'이라며 뺐어요. 그래서 마법사의 신발은 관통 태그를, 탱커 아이템은 제어·가속 태그를 잃었어요. 그 결과 탱커·전사 27명의 빌드가 바뀌고 공식 담기가 77 → 72로 떨어졌어요. 그래서 기본 능력치로 계산되는 태그는 '능력치 선호'로 남기는 E3(`TAG_DEDUP=unique`)를 새로 만들었어요.

## 3. `allysupport` 분류와 실제 지원 능력

- **분류 규칙:** 스킬 설명 하나에 '아군'과 '회복·보호막'이 함께 있으면 `allysupport`이고, 그러면 회복·보호막 특성을 **1.0으로 고정**해요. 다른 특성은 '나온 스킬 수 × 0.4'예요.
- **결과:** 실제 지원 몫(맨몸 지원 ÷ (한타 피해 + 지원))이 12%인 럭스와 83%인 소라카가 같은 1.0을 받아요. Riot 역할 '서포터'(1.0)까지 더하면 둘 다 회복·보호막 가중치가 1.4예요.
- **분류는 됐지만 지원 수치가 0인 챔피언:** 닐라·루시안·헤카림. 설명 문장에 우연히 걸렸거나, 아군 효과를 계산하지 않아서예요.

다른 특성과 같은 규칙(지원 수치가 나오는 스킬·패시브 수 × 0.4, 최대 1)으로 바꾸면(E2):

| 회복·보호막 특성 | 챔피언 (맨몸 지원 몫) |
|---|---|
| 0 | 닐라·루시안·헤카림 (0%) |
| 0.4 | 럭스 12%, 흐웨이 11%, 쓰레쉬 14%, 멜 19%, 세라핀 21%, 오리아나 21%, 애니 26%, 갈리오 41%, 바드 66%, 질리언 86% … |
| 0.8 | 소나 23%, 나미 36%, 카르마 52%, 쉔 91% … |
| 1.0 | 소라카 83%, 잔나 81%, 룰루 78%, 타릭 90%, 밀리오·유미·레나타·라칸 |

- 지원 몫과 대체로 같은 방향이에요. 하지만 질리언(부활 R 미계산)과 바드(이동 속도 미계산)는 스킬 수가 적게 잡혀요.
- 역할 기본값(Riot '서포터' 1.0)은 그대로라, 럭스는 1.4 → 1.16으로만 줄어요.

## 5. 해석

- **E2는 근거가 가장 분명하고 부작용이 작아요.** 1.0 고정이라는 특례를 다른 특성과 같은 규칙으로 바꾸는 것이에요. 바뀌는 건 아군 지원 3명뿐이에요(럭스·카르마 구원 → 폭풍 쇄도·공허, 세라핀 향로 → 라바돈). 다만 역행 개선은 작아요(럭스·소나 13 → 11).
- **E3은 중복 보상을 직접 빼요.** 하지만 남은 태그와 비대칭이 생겨요. 계산되는 효과는 태그를 잃는데, 계산 안 되는 효과(슈렐리아의 아군 이동 속도)는 능력치 태그와 공식 가산을 그대로 받아요. 그래서 나미·잔나·룰루 빌드에 슈렐리아가 들어와요. 탱커 2명(오른·자크)은 공식 핵심인 얼어붙은 건틀릿을 잃었어요(공식 담기 −1).
- **E2+E3은 점검표 숫자가 가장 좋아요.** 잘 따라감 +43, 역행 −8, 몰빵 < 균형 17 → 7, 럭스·소나 역행 13 → 6이에요. 하지만 바뀌는 장면이 958개로 넓고, 적합성 표시도 +6이에요.
- **남은 원인:** 역행의 다른 원인인 P1 가정 2(아군 강화를 지속시간 전부로 셈)는 이번 실험에 들어 있지 않아요.

## 6. 제안 (승인 필요)

1. **E2를 기본값으로 적용 (권장).** 데이터 단계(`build_data.py`)에서 1.0 고정 대신 같은 규칙으로 바꿔요. 지금은 실험용으로 실행 중에 계산하는데, 적용하면 데이터 단계로 옮기고 테스트를 붙일게요.
2. **E3은 P4와 함께.** 미계산 효과(아군 이동 속도 등)를 계산하기 전에 계산된 효과 태그만 빼면, 미계산 아이템이 상대적으로 유리해져요. P4에서 아군 이동 속도 같은 효과를 계산한 뒤 E3을 다시 재는 순서가 맞다고 봐요.
3. **이번에 하지 않은 것:**
   - Riot 역할 기본값(서포터 회복·보호막 1.0) 조정.
   - 공식·연계 가산 비중 조정.
   - 닐라·루시안·헤카림의 `allysupport` 분류 수정.
   - 지원 지표의 자기용/아군용 분리.
   모두 근거 자료와 영향 분석이 따로 필요해요.
