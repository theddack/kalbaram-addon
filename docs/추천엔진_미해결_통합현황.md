# 추천 엔진 미해결 통합 현황 (2026-11-12, v0.1.87)

「추천 계산 정확도 고도화 기획서 v1.0」 P0 산출물이에요. 기존 문서 9개의 미해결 항목과 가정을 모으고, 하나씩 v0.1.87 코드와 다시 대조했어요.

- 기준: `main` v0.1.87 (`ff658f7`), 게임 데이터 16.22.8348910
- 다시 돌린 도구: `augment_quality.js`, `official_diff.js`, `aug_audit.js`, `unimpl_triage.js`, `assume_sensitivity.js`, `rec_baseline.js`, `augment_regress.js`
  - 생성 문서(`공식_추천_차이.md`·`미구현_분류.md`·`가정값_목록.md`·`증강_원본_대조_결과.md`)는 덮어쓰지 않았어요. 예전 조사를 그대로 두고, 이 문서에 현재 숫자를 적었어요.
- 모두 **계산끼리의 비교**예요. 실게임 검증은 하나도 포함하지 않아요.

상태 표기:
- **해결:** 해결 버전과 근거를 확인함
- **열림:** 코드에서 아직 그대로임
- **가정 유지:** 원본으로 정할 수 없어 사람이 정한 값
- **실게임:** 기록으로만 확인할 수 있음
- **범위 밖:** 추천 엔진이 아님

우선순위는 기획서 4장 기준이에요.
- P0: 실제 계산 오류
- P1: 직접 전투 수치 누락이나 민감한 가정
- P2: 챔피언 특수 효과
- P3: 태그 기반 효과

## 1. 새로 확인한 실제 계산 오류

### N1. 증강의 '원거리 챔피언 배율'(mRangedMultiplier)이 계산에 없음 — P0, 열림

**근거 (게임 데이터 `kiwi.bin.json`)**
- 증강 12개의 계산식에 원거리 배율이 있어요.
- 위키도 같은 값을 써요. 붐 앤 베이스는 "50 to 200 | 25 to 100"(근접 | 원거리)이에요.

**코드**
- `build_data.py` 는 아이템의 근접/원거리 값(`Item_Melee_Ranged_Split`)만 `rangedScale` 로 옮겨요(414–434행).
- 증강 계산식의 `mRangedMultiplier` 는 읽지 않아요.
- 증강 쪽은 rules.json 에 손으로 적은 해악의 숫자 3 `Calc_Damage` 하나만 반영돼 있어요.

| 증강 | 원거리 배율이 붙은 값 | 계산에 쓰는가 | 영향 |
|---|---|---|---|
| 붐 앤 베이스 | 마법 피해 ×0.5 | 쓰임 (효과 `Calc_Damage`) | **과대**: 원거리도 근접 피해로 셈 |
| 전부 다 무너뜨려 | 피해·중첩당 피해·폭발 ×0.5 | 쓰임 (효과 2개) | **과대** |
| 해악의 숫자 3 | 중첩당 고정 피해 10 ×0.5 | 쓰임 (`Calc_Damage_Per_Stack`) | **과대** (최대 체력 6%는 이미 ×0.5) |
| 유리 대포 | 추가 고정 피해 25% ×0.6 (원거리 15%) | 쓰임 (`trueBonus`) | **과대** |
| 민병대 | 이동 속도 ×0.75 | 가정값 0.3 (가동률) | 작음 (이동 속도만) |
| 작은 도움 · 조준경 3종 | 사거리·공격 속도 | 태그만 | 수치 영향 없음 |
| 전장의 교향곡 · 도취 | 피해 | 태그만 | 수치 영향 없음 |
| 죽음의 무도 업그레이드 | 고통 무시 40% (원거리 15%) | 계산 안 함 | 수치 영향 없음 |

**붐 앤 베이스에만 원거리 ×0.5를 넣어 본 결과** (`augmentTiers`, 종합 1위, 전 챔피언 173명)

| | 지금 | ×0.5 적용 |
|---|---|---|
| 첫 증강 1위로 고르는 챔피언 | 38 (근접 30, 원거리 8) | 30 (전원 근접) |
| 붐 앤 베이스 S 등급 | 102 | 77 |

- 빠지는 원거리 8명: 니달리·아지르·엘리스·우르곳·케넨·코그모·트위스티드 페이트·티모
- 나머지 3개 증강까지 고쳤을 때의 결과는 2차(P1)에서 전 챔피언 회귀로 재요.

**검증 방법:** 원거리·근접 챔피언 한 쌍의 효과 값 비율 테스트(0.5·0.6)를 수정 전에 실패하도록 만든 뒤 고쳐요.

### N2. 붐 앤 베이스가 근접 30명의 1위인 이유 — 계산 오류 근거 없음, 가정 유지

**원본**
- "스킬을 쓴 뒤 6초 안의 **다음** 기본 공격"이 강화돼요(`Charge_Duration 6`).
- 강화된 공격은 공격 속도 +200%, 피해 50~200(레벨) + 추가 공격력 50% + 주문력 30%, 이동 속도 75~150%(2초 감소)를 줘요.
- 충전은 하나라서, 스킬을 다시 쓰면 갱신돼요.

**코드 (`stats.js` metrics 의 `cast` + `needsAuto`)**
- 콤보 한 번에 강화 평타 = 쓴 스킬 수(최대 4) × 평타 섞는 비율(`weaveOf`, 라이엇 공격 의존도로 25~100%). 4초 동안 칠 수 있는 평타 수가 상한이에요.
- 초당 횟수 = 스킬마다 최대 2초에 1번 × 비율. 공격 속도가 상한이에요.
- 주문 검(리치베인·삼위일체)과 같은 기준이에요.

**판단**
- 스킬과 평타를 번갈아 쓰는 근접 브루저·암살자에게 크게 나오는 건 원본 효과와 맞아요.
- 강화 평타의 공격 속도·이동 속도는 계산하지 않아요. 그래서 오히려 조금 낮게 잡혀요.
- 따라서 근접 30명은 계산대로 둬요.
- "스킬 사이마다 평타 1번"은 가정이에요. 스킬을 몰아 쓰면 1번만 터져요. → 실게임 확인 목록 G6

### N3. 전부 다 무너뜨려의 발동 조건 — P1, 확인 필요

- 원본 설명은 "기본 공격 **및** 스킬이 적 챔피언에게 중첩"이에요.
- 그런데 자동 추출은 '스킬 사용 후 평타'(`cast` + `needsAuto`)로 읽었어요. 그래서 평타 적중만으로 쌓이는 경우가 빠져 있을 수 있어요.
- 5중첩 폭발(잃은 체력 17%)과 회복(입힌 피해 67%)은 미구현이에요.
- 원본 문구와 계산 구조를 맞춰 본 뒤 2차에서 다뤄요.
