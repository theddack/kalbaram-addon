# F5 — 초당 피해에서 빠지는 스킬 23개 조사 · 수정안 (v0.1.95 Phase 4, C9-B 선행)

조사만 했다. **계산 로직은 아직 하나도 바꾸지 않았다.** 수정안을 검토받은 뒤에 고친다.
도구: `node tools/f5_audit.js` (챔피언 이름 일부를 주면 한 명만). 게임 데이터 파일(`.cache/bins`)의 값만 근거로 쓴다.

## 0. 맨 위에 둘 것 (확인 못 한 것)

- **실제 게임 확인 0건.** 아래 분류는 게임 데이터 파일의 값과 스킬 설명 원문으로만 가린 것이다.
- **쿨타임이 어디에도 없는 스킬이 3개 있다** (베이가 W · 쉬바나 R · 탐 켄치 R). 게임 파일에도 Data Dragon 에도 0 이다.
  **임의로 채우지 않았다.** 출처를 새로 붙이는 안은 §4 에 적고 승인 전에는 손대지 않는다.
- **중복 합산이 의심되는 자리 3건**(카서스 Q · 럼블 E · 칼리스타 E)을 새로 찾았다. 쿨타임 문제와 원인이 다르다 (§3).
- 피해 유형(물리·마법·고정)은 설명 원문의 표시 그대로다. 23개를 눈으로 대조했고 어긋난 것은 없었지만,
  **전수 검증은 F14(챔피언 스킬 수치·효과 검증)** 의 몫이다.

## 1. 지금 무슨 일이 일어나는가

`web/stats.js` 의 초당 피해:

```js
if (cdBase > 0.5) out.skillDps += dmg / Math.max(cd, 0.5);
```

원래 뜻은 "징크스 Q 무기 바꾸기 같은 전환형은 초당 피해에서 뺀다" 인데,
**데이터의 재사용 대기시간이 0 인 스킬까지 같이 빠진다.** 173명 중 **19명 · 스킬 23개**가 걸린다.

경로별로 지금 어떻게 세는지:

| 경로 | 23개 스킬이 들어가는가 |
|---|---|
| `combo` (한타 한 번 피해) | **들어간다** — 23개 모두. 콤보 쪽 누락은 없다 |
| `spellOnhit` → `autoDps` (평타에 얹히는 피해) | 2개만 (유나라 Q 15 · 티모 E 221). 설명에 '적중 시' 가 있는 효과만 |
| `skillDps` → `dps` (추천 점수) | **하나도 안 들어간다** ← 문제 자리 |
| `castRate` (스킬 사용 시 효과의 발동 횟수) | `s.cd > 0` 조건이라 쿨 0 인 것은 빠진다 (증강 발동 횟수도 같이 적게 센다) |

평타와 스킬의 **중복 계산은 없다**: `onhit` 로 표시된 효과는 `continue` 로 콤보에서 빠지고 평타 쪽으로만 간다.

## 2. 23개를 발동 구조로 가른다 (근거: 게임 데이터 파일의 값)

가른 기준은 전부 게임 파일에 있는 값이다 — `mMaxAmmo`·`mAmmoRechargeTime`(충전), `bIsToggleSpell`(토글),
`PositiveEffect_EmpowerAttack`·`Trait_AttackBuff_Duration`(평타 강화), `Trait_PassiveSlot`(패시브 칸), `Trait_DoT`(지속 피해).

### (가) 충전형 — 스킬 10개 · 챔피언 8명 (렝가가 Q·W·E 셋) — 데이터에 발동 간격이 있다

| 챔피언 | 스킬 | 데이터 쿨 | 충전 | 1개 차는 데 (최대 랭크) |
|---|---|---|---|---|
| 갱플랭크 | E 화약통 | 0 | 3~5개 | 13초 |
| 닐라 | E 급류 | 0.5 | 2개 | 12초 |
| 럼블 | E 전기 작살 | 0.5 | 2개 | 6초 |
| 렝가 | Q 포악함 | 0.25 | 1개 | 4초 |
| 렝가 | W 전투의 포효 | 0.25 | 1개 | 10초 |
| 렝가 | E 올가미 투척 | 0.25 | 1개 | 10초 |
| 아이번 | W 수풀 가꾸기 | 0.5 | 3개 | 20초 |
| **카서스** | **Q 황폐화** | **0** | **2개** | **1초** |
| 케이틀린 | W 요들잡이 덫 | 0.5 | 2~5개 | 10초 |
| 티모 | R 유독성 함정 | 0.25 | 3~5개 | 25초 |

오래 싸울 때의 발동 간격은 '충전 1개가 차는 시간' 이다 — **짐작이 아니라 게임 파일 값**이라 공통 규칙으로 해결된다.
(챔피언 수로는 8명이다.)

### (나) 토글형 8개 — 켜 두는 것이라 '한 번 쓰는 피해' 가 아니다

신지드 Q 맹독의 자취 · 카서스 E 부패 · 티모 E 맹독 다트 · 조이 W 주문도둑 · 칼리스타 E 뽑아 찢기 ·
렝가 W · 아이번 W · 럼블 E (뒤 셋은 충전형과 겹친다).

- 신지드 Q(`damagepersecond` 130) · 카서스 E(`totaldps` 234) · 티모 E(`totaldotdamage`) 는 **수치 자체가 이미 초당 피해**다.
  그대로 `skillDps` 에 더하면 맞지만, **몇 % 켜 두는지(가동률)** 를 정해야 한다 → 임의 수치 금지, §4-나 참조.
- 칼리스타 E 는 토글 표시가 붙어 있지만 실제로는 '창 중첩을 터뜨리는' 소모형이다. 발동 간격의 근거가 데이터에 없다.

### (다) 평타 강화형 4개 — 피해가 기본 공격을 타고 들어간다

| 챔피언 | 스킬 | 게임 표시 | 지금 |
|---|---|---|---|
| 애쉬 | Q 궁사의 집중 | `Trait_AttackReset`·`Trait_AttackBuff_Duration`·`Trait_NoCooldown` | 콤보에만 (423 물리) |
| 유나라 | Q 영혼 단련 | `PositiveEffect_EmpowerAttack`·`Trait_NoCooldown` | 적중 몫 15 만 평타로 |
| 트위스티드 페이트 | E 속임수 덱 | `PositiveEffect_EmpowerAttack`·`Trait_PassiveSlot` | 콤보에만 (422 마법) |
| **제리** | **Q 집중 사격** | 설명 원문: **"이 스킬은 기본 공격으로 간주됩니다"** | 콤보에만 (374 물리) |

**제리 Q 는 기본 공격 그 자체다.** 초당 스킬 피해로 더하면 평타와 이중 계산이 된다 — 되살릴 자리는 `skillDps` 가 아니라 평타 쪽이다.

### (라) 패시브 칸 3개

조이 W · 트위스티드 페이트 E · 티모 E — 스킬 칸에 있지만 눌러 쓰는 스킬이 아니다 ((나)·(다)와 겹친다).

### (마) 쿨타임 근거가 아예 없는 3개 + 1개

| 챔피언 | 스킬 | 게임 파일 | Data Dragon | 무엇이 발동을 막는가 |
|---|---|---|---|---|
| 베이가 | W 암흑 물질 | `cooldownTime` 전부 0 | 0 | **데이터에 근거 없음** |
| 쉬바나 | R 용의 강림 | 0 · `mDoesNotConsumeCooldown` | 0 | 용의 분노(자원)로 쓴다 — 쿨타임이 아니다 |
| 탐 켄치 | R 집어삼키기 | 0 (래퍼 스킬 `TahmKenchRWrapper`) | 0 | 래퍼라 실제 값이 다른 레코드에 있을 수 있는데, 같은 챔피언 파일 어디에도 없다 |
| 야스오 | E 질풍검 | 0.5→0.1 · `mDoesNotConsumeCooldown` | 0.5/0.4/0.3/0.2/0.1 | 쿨은 진짜 짧고, 실제로는 **같은 대상에게 다시 못 쓴다** (대상별 제한, 데이터에 없음) |

**정상적으로 제외된 것과 계산 오류의 구분**

- 정상 제외: 토글형 (나) · 평타 강화형 (다) · 패시브 칸 (라) — 이들을 `skillDps` 에 그냥 더하면 오히려 과대계산이다.
- 계산 오류: 충전형 (가) — 게임이 발동 간격을 가지고 있는데 0.5초 경계선에 걸려 **통째로 빠졌다**.
- 판단 보류: (마) 4개 — 데이터에 근거가 없다. 지금처럼 빼 두는 쪽이 임의 수치보다 안전하다.

## 3. 덤으로 찾은 것 — 중복 합산 의심 3건 (쿨타임과 다른 원인)

`spellTotals` 는 서로 대안인 효과를 하나만 남긴다(`spellPlan` 의 cards). 이름 줄기가 다르면 못 가른다.

| 챔피언 | 남은 값 | 설명 원문 | 판단 |
|---|---|---|---|
| 카서스 Q | `qdamage` 332 + `qsingletargetdamage` 664 = 996 | "하나의 적만 맞힐 경우" | **둘 중 하나여야 한다** |
| 럼블 E | `totaldamage` 475 + `empdamage` 712 | 과열 시 강화 | 대안으로 보인다 |
| 칼리스타 E | `normaldamage` 285 + `additionaldamage` 206 | 창 수에 따른 추가 | 합이 맞을 수도 있다 — 원문 재확인 필요 |

렝가 Q·W·E 와 야스오 E 는 제대로 하나만 남는다(도구가 "원본 효과 2개 중 1개만 셈" 으로 찍는다).
카서스 Q 는 **충전형 되살리기와 겹치는 자리**라, 고치는 순서를 잘못 잡으면 과대계산이 두 배가 된다 → §4 의 순서를 지킨다.

## 4. 수정안

### 공통 계산 규칙으로 되는 것

1. **충전형 발동 간격** — 스킬 데이터에 `maxAmmo`·`ammoRecharge` 를 실어 보내고(`build_data.py`),
   `stats.js` 에서 `cdBase` 가 0.5 이하이고 충전 값이 있으면 **발동 간격 = 충전 1개가 차는 시간**으로 본다.
   랭크 대응은 이미 있는 규칙(`champion_data` 의 `[1:랭크+1]`)을 그대로 쓰고, 0 이 나오면 쓰지 않는다
   (티모 R 의 첫 칸이 0 이다 — 이 함정을 조사 중에 밟았다).
2. **`castRate` 조건** — `s.cd > 0` 대신 '충전 간격이라도 있으면' 으로 넓힌다 (증강 발동 횟수가 같이 적게 세지던 자리).
3. **대안 효과 가르기** — `spellPlan` 이 '단일 대상 / 광역', '강화 / 기본' 을 같은 줄기로 묶도록 이름 규칙을 넓힌다.
   **1번보다 먼저 한다** (카서스 Q 때문).

### 챔피언별 규칙이 필요한 것 (`rules.json` 에 적는다)

4. **평타 강화형 4개** — `skillDps` 가 아니라 평타 경로로 보낸다. 제리 Q 는 **평타를 대체**하므로 더하지 말고 평타 피해를 갈아끼워야 한다.
5. **지속 피해 토글 3개**(신지드 Q · 카서스 E · 티모 E) — 수치가 이미 초당 피해다. 가동률을 `rules.json` 의 가정값으로 적고
   근거(설명 원문·지속시간)를 같이 남긴다. **가동률 수치는 승인 뒤에 정한다.**
6. **(마) 4개** — 두 갈래 중 하나를 골라야 한다. ① 지금처럼 제외 유지(기본값, 추천 변화 없음) ②
   위키 챔피언 표의 재사용 대기시간을 새 출처로 받아오기(`build_data.py` 에 경로 신설, 값의 출처가 생긴다).
   **①을 기본으로 두고, ②는 따로 승인받는다.**

### 안 하는 것

- 쿨타임이 0 이라는 이유만으로 임의의 값을 넣지 않는다.
- 23개를 한 규칙으로 뭉뚱그려 초당 피해에 더하지 않는다.
- 가중치·목적 함수·기준선은 건드리지 않는다.

## 6. 검증 계획 (고칠 때 그대로 쓴다)

1. **전 챔피언 173명** — 수정 전후 1순위·Top3·6칸 빌드·증강 등급 (`tools/aug_top3_dump.js`, `tools/rec_baseline.js`).
2. **피해 경로별** — 평타·스킬·콤보·초당 피해를 따로 찍어, 되살린 피해가 **한 경로에만** 들어갔는지 본다
   (특히 제리·애쉬·유나라·트위스티드 페이트: 평타와 스킬 양쪽에 들어가면 실패).
3. **피해 유형 비중** — `tools/ally_damage_mix.js` 로 물리·마법·고정 비중 변화 (C9-B 의 기준 아군 모델에 닿는다).
4. **안 바뀌어야 하는 쪽** — 23개와 무관한 154명은 **한 칸도 바뀌면 안 된다**. 바뀌면 그 자체가 오류다.
5. **기존 기준선 263장면 · 실게임 기록 169장면** — `tools/c9_shred_check.js --cmp`. 바뀐 장면은 원인을 하나씩 적는다.
   **기준선 파일은 갱신하지 않는다.** 의도한 변화는 수정 항목별로 문서에 쌓는다.
6. **성능·캐시** — `tools/perf_check.js`, 같은 입력 두 번·캐시 초기화 뒤 결과 일치.
7. 비교는 `tools/engine_fp.js` 의 분류(엔진 변경 / 데이터 변경 / 입력값 민감도 / 동일 조건 재현)를 함께 찍는다.

**특정 챔피언의 순위를 미리 정해 두고 계산식을 맞추지 않는다.** 카서스의 마법 비중이 올라가는 것은 결과이지 목표가 아니다.

## 8.3 충전형을 켠 기준 — 사용 횟수와 피해 횟수를 가른다

| 가른 항목 | 켠 5개 | 안 켠 4개(설치물) | 렝가 Q |

**초기 충전량을 두 번 세지 않는다**: 한타 한 번 피해(`combo`)는 예전처럼 스킬 한 번만 센다.

렝가 Q 는 설명이 "첫 번째 공격은 20~160 + 110~125% 공격력의 물리 피해" 라 **기본 공격 한 대의 전체 피해**다.
