# 추천 엔진 원인 분석 · 개선 설계 (2026-11-14)

증강 → 아이템 점검표(`docs/증강_아이템_점검표.md`)에서 드러난 문제의 원인을 엔진 구조부터 다시 확인했어요.
**이 문서는 분석과 설계만 담아요. 엔진 코드는 바꾸지 않았어요.**

## 기준과 방법

- 코드: PR #128 브랜치(v0.1.90 + 챔피언 패시브 21명)
- 표본: 역할별 대표 18명 × 수치가 있는 증강 180개 = 3,038장면 (`node tools/augment_fit.js`)
- **목표 함수 재구현**
  - `buildWith` 의 점수 = (빌드 가치 + 증강 몫 × focus) × 4 + (태그 + 공식 추천 가산 + 규칙 가산) × 0.4
  - 이 식을 그대로 다시 만들었어요. 엔진이 낸 점수와 소수 셋째 자리까지 같아요(징크스·사이온·가렌 확인).
- **교체 탐색**
  - 엔진 빌드에서 전설 아이템 한 칸씩 바꿔 점수가 오르면 받아들이는 방식이에요.
  - 엔진과 같은 제약을 근사했어요: 주 피해 유형 반대 막기, 치명타 못 쓰는 챔피언, 필수 아이템, 같은 계열.
- 세 가지 값
  - **J** = 몰빵 목표 함수
  - **V** = 전체 전투 가치(균형 가중치, 증강 포함)
  - **A** = 증강 자체 효과(성향 가중치 없이, 증강이 늘린 지표를 맨몸 대비로 더한 값)
- 모두 계산 결과끼리의 비교예요. 실게임 검증은 포함하지 않아요.

## 2. 탐색 알고리즘 문제 목록

`buildWith`: 신발 1칸(후보 2) → 필수 아이템 → 전설 5칸을 빔 6개, 후보당 다음 아이템 5개(즉시 점수 순)로 채워요.

| ID | 문제 | 근거 |
|---|---|---|
| S1 | **한 칸 앞만 보고 후보를 자름** | 후보는 "지금 넣었을 때 점수" 상위 5개만 남아요. 다른 아이템과 함께여야 커지는 아이템이 일찍 탈락해요. 레오나 + 핀볼: 워모그는 단계마다 5~14위라 빔에서 매번 잘려요. 하지만 마지막에 지크의 융합과 바꾸면 총점이 13.03 → 13.71로 올라요 (체력 가치 = 체력 × 저항이라 방어 아이템이 쌓인 뒤 커져요) |
| S2 | **상한이 있는 효과를 일찍 고정** | 헬리아의 메아리(회복 상한 80~250)는 처음엔 커 보여요. 하지만 뒤에서 피해가 늘어도 더 안 늘어요. 탐색 실패 275장면 중 헬리아 → 다른 아이템 교체가 132회예요 |
| S3 | 태그 감쇠가 순서에 따라 달라짐 | 같은 태그를 또 고를수록 0.7배라, 같은 아이템 5개도 순서에 따라 총점이 달라요 |
| S4 | 신발을 먼저 고정 | 전설 아이템 없이 신발(후보 2개)을 먼저 정해요 |

- **탐색 실패 규모**
  - 2,209장면 중 275장면(12%)이에요. J 차이 중앙값은 2.9%예요.
  - 레오나 84 · 나미 88 · 룰루 47에 몰려 있어요.
  - 이렐리아 + 붐 앤 베이스(+83%)는 제 근사 제약이 주문력 아이템을 허용해서 생긴 착시예요(엔진은 막음).
- **빔 크기 문제가 아니에요.** 원인은 한 칸 앞 점수로 자르는 방식(S1·S2)이에요.
- 그래서 빔을 키우는 대신 **빔 뒤에 같은 목표 함수로 한 칸 교체 탐색**을 붙이는 게 맞아요. 결과는 항상 같거나 좋아져요.

## 3. 균형·몰빵 목표가 코드에서 구분되는가

| 항목 | 균형 | 몰빵 | 판정 |
|---|---|---|---|
| 태그 가중치 | 챔피언 1 + 증강 lift 0.7 | 챔피언 0.35 + 증강 lift 1.2 | **lift가 비면(128/180) 둘 다 챔피언 가중치 그대로** |
| 지표 가중치 | 위 가중치에서 | 위 가중치에서 | 같은 방식 |
| 증강 몫 | 없음 | + 1 × 증강 몫 (챔피언 성향 가중치로 잼) | 유일한 차이. 크기가 작아요 (징크스 + 강타자 1.2 / 31.3) |
| 공식 추천 가산 | 있음 (+3 × 0.4) | **있음 (같은 크기)** | 몰빵을 공식(증강 없는 기준) 아이템으로 붙잡아요 |
| 코어 제한 | 코어 밖 반대 유형 2~3칸 | 없음 | 구분됨 |

결론: **목표가 코드에서 거의 구분되지 않아요.** 몰빵 = 기본인 1,942장면(64%)의 직접 원인이에요.

## 4. "못 따라감" 2,209장면 분류

"못 따라감"은 달성률 0~30%인 장면이에요. 달성률 = (몰빵 − 기본) ÷ (증강만 키운 상한 − 기본), 전체 3,038장면의 72.7%예요. 가중치를 바꾸지 않고 원인만 나눴어요.

| 분류 | 장면 | 비율 | 판정 기준 |
|---|---:|---:|---|
| **목표 함수 왜곡** | **757** | 34% | 증강 효과(A)와 전투 가치(V)가 **둘 다** 나아지는 빌드가 있는데 J가 더 낮게 봄 |
| **탐색 실패** | 275 | 12% | 같은 J·같은 제약으로 0.5% 넘게 높은 조합이 있음 |
| **계산 누락** | 258 | 12% | 그 증강의 직접 전투 수치가 계산에 없음 (E6) |
| **정상 유지** | 919 | 42% | 증강을 더 살리려면 전투 가치를 내줘야 함 (맞바꿈) |

### 4.1 증강 효과와 전투 성능이 모두 개선되는 빌드를 놓친 사례 (942장면)

- 증강 효과 배율 중앙값 **1.39배**, 전체 전투 가치 중앙값 **+3.9%**예요. 둘 다 좋아지는데 엔진이 고르지 않았어요.
- **912장면(97%)에서 J가 그 빌드를 더 낮게 봤어요.** 성분을 쪼개면 원인이 하나예요.

| 성분 (대체 − 엔진, 평균) | 값 |
|---|---:|
| 수치(빌드 가치) | **+0.45** |
| 증강 몫 | **+0.15** |
| 태그 | −0.27 |
| **공식 추천 가산** | **−2.54** |

- 대체 빌드를 떨어뜨린 가장 큰 성분: **공식 추천 가산 907장면** · 수치 4 · 태그 1
- 동시 개선 빌드에 새로 들어간 아이템
  - 그림자불꽃 236 · 불경한 히드라 136 · 내셔의 이빨 131 · 그림자 검 121 · 세릴다의 원한 119
  - 폭풍 쇄도 114 · 구인수 102 · 무덤꽃 100 · 케이닉 루컨 84 · 워모그 77
- 즉 **공식 추천 가산점(아이템당 최대 +1.2)이 수치 이득(보통 0.4~1.2)보다 커서**, 증강과 전투 둘 다에 더 좋은 아이템을 밀어내요.
  - 공식 추천은 증강 없는 챔피언 기준이에요. 그래서 증강을 따라가야 하는 몰빵의 목적과 부딪혀요.

### 4.2 정상 유지 919장면

- 증강을 더 살리려면 전투 가치를 내줘야 하는 경우예요. 징크스 + 강타자가 대표적이에요.
  - 체력 빌드로 가면 증강 몫은 1.2 → 3.6이 되지만, 빌드 가치는 28.4 → 10.0으로 떨어져요.
- 현재 목표(전체 가치 + 증강 몫)에선 맞는 결과예요.
- 바꾸려면 몰빵의 목표를 다시 정해야 해요(설계 D6, 사용자 결정). 원딜(212)·암살자(209)·전사(184)가 많아요.

## 6. 개선 설계 (우선순위 · 예상 영향)

임의 가중치·챔피언별 예외는 넣지 않아요. 각 항목은 근거와 측정 방법을 함께 둬요.

| 순위 | 항목 | 내용 | 근거 | 예상 영향 | 결정 필요 |
|---|---|---|---|---|---|
| 1 | **D1 몰빵에서 공식 추천 가산 빼기** | 몰빵 컨셉의 공식 추천 비중을 변칙처럼 0으로 (균형은 그대로) | 공식 추천은 증강 없는 기준. 동시 개선 빌드 912장면 중 907장면을 이것이 막음 | 목표 함수 왜곡 757장면 해소 예상. 균형·기본 추천은 변화 없음 | 예 (공식 추천 쓰임새) |
| 2 | **D2 빔 뒤 교체 탐색** | 빔 결과에서 같은 목표 함수·같은 제약으로 한 칸 교체를 반복 | 결과는 항상 같거나 좋아짐. 원인은 한 칸 앞 자르기(S1·S2) | 탐색 실패 275장면 (서포터·탱커). 계산 시간 증가는 측정 필요 | 아니요 |
| 3 | **D3 스킬 사용 시 효과 30%** | cast 효과 초당 피해도 스킬 피해와 같은 30% | 같은 가정을 같은 대상에 (E1) | 주문 검·붐 앤 베이스·전부 다 무너뜨려 장면 | 아니요 |
| 4 | **D4 lift 자동 산출 보강** | 효과의 발동 방식(적중 시 → 공속·적중, 스킬 → 가속)·대상 비례·변환 키에서 비례 능력치를 읽기 | E2 (128/180이 비어 있음) | 몰빵이 증강 쪽으로 가중치를 옮기는 장면 증가 | 아니요 |
| 5 | **D5 증강 몫을 성향 중립으로** | 몰빵 focus 항의 증강 몫을 지표 가중치 없이(점검표의 A처럼) 잼. 태그는 "비례 능력치"와 "지표"를 나눔 (E3·E5) | 탱커의 피해 증강 가치 0.03 | 탱커·서포터 장면 | 예 (몰빵 정의) |
| 6 | **D6 몰빵 목표 재정의 (제약형)** | 증강 몫 최대화, 단 전체 전투 가치 ≥ (1 − δ) × 균형 빌드 가치 | 정상 유지 919장면의 맞바꿈을 "어디까지 허용할지"의 문제 | δ에 따라 원딜·암살자 장면이 크게 바뀜 | **예 (δ 값)** |
| 7 | D7 효과 0·아이템 무관 안내 | 증강이 그 챔피언에게 0이거나 아이템으로 못 키우면 화면에 안내 | 219장면 (가렌 + 사악한 정신 등) | 화면만 | 아니요 |
| 8 | D8 계산 누락 메우기 | E6 P0 중 원본 값이 있는 것부터, E7 퀘스트 보상(완료 시점 가정), E8 제이스 | 258장면 | 증강별 | 일부 (가정) |

- 진행 순서 제안: D1·D2·D3을 먼저 하고 다시 측정해요.

- 그다음 D4·D5를 하고, D6(δ)은 결과를 보고 정해요.

## 7. 수정 후 검증 방법

1. **점검표 다시 재기**: `node tools/augment_fit.js --write`
   - 몰빵 = 기본 비율(지금 64%), 달성률 분포(못 따라감 72.7%)
2. **4분류 다시 재기**
   - 이번에 쓴 분석 스크립트를 `tools/` 로 옮겨 같은 기준으로 다시 돌려요.
   - 목표 함수 왜곡·탐색 실패가 0에 가까워지는지 봐요.
   - 정상 유지는 D6 결정 전까지 남는 게 맞아요.
3. **역할별 기존 지표**
   - `augment_regress.js`: 균형<기본 0 유지, 몰빵<균형 감소
   - `augment_quality.js`: 몰빵 살림 비율
   - `rec_baseline.js`: 증강 없는 기본 추천은 D1·D2에서 바뀌지 않아야 해요
4. **성능**: `tools/perf_check.js`. 교체 탐색 추가 뒤 빌드 3종 계산 시간
5. **새 테스트 (성질 검사, 특정 아이템 고정 아님)**
   - 교체 탐색 뒤 같은 목표 함수로 더 좋은 한 칸 교체가 없다
   - 몰빵 빌드의 증강 몫 ≥ 균형 빌드의 증강 몫
   - 몰빵 목표에 공식 추천 가산이 없다 (D1)
   - 스킬 사용 시 효과와 스킬 피해가 같은 비율 (D3)
6. **실게임**
   - 자동 검증은 계산끼리의 일관성이에요.
   - 평타 가동률·왕관의 무게 중첩·전부 다 무너뜨려 중첩은 게임 기록으로만 정할 수 있어요.
