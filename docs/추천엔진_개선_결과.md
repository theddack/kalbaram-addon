## 2. 증강 연계 구조 변경 (P2)

**P2-1 입력 능력치(lift)를 계산에서 읽기** (`scaleTags`)
- 효과 계수(식 나무 포함)를 읽어요.
- 발동 방식을 읽어요: 평타 → 공격 속도·적중, 스킬 → 가속, 치명타 확률 발동 → 치명타.
- 변환 키의 입력을 읽어요: 유레카 주문력, 치명적 리듬 치명타, 간지럼 괴물 공격력 등.
- 대상 체력 비례는 자기 아이템과 연결하지 않아요.
- lift가 빈 128개의 분류

| 원인 | 수 | 처리 |
|---|---:|---|
| 고정 능력치만 | 67 | 비워 둠 (아이템으로 안 커짐) |
| 모든 피해 배수 (속전속결·처형 시간 등) | 13 | 비워 둠 |
| 고정 피해·회복 (계수 없음) | 8 | 비워 둠 |
| 기타 (업그레이드 골드 등) | 8 | 비워 둠 |
| **변환 키 입력 미연결** | 14 | 연결 |
| **효과 계수가 표에 없음 / 태그에 없음** | 12 | 연결 |
| **평타·스킬 발동 비례** | 6 | 연결 |

**P2-2 입력과 출력 분리** (`conceptMetricWeights`, `augOutputWeights`)
- 전체 전투 가치는 **챔피언 성향 지표 가중치 그대로**예요(증강 태그를 섞지 않음).
  - 강타자(체력 비례 피해)의 체력 태그가 버티는 힘 가중치로 새던 E3 문제가 없어져요.
- 몰빵의 "증강 몫"은 **증강 출력**(맨몸에 넣었을 때 실제로 늘어나는 지표) 가중치로 재요.
  - 사이온 + 강타자의 증강 몫이 0.03이던 E5 문제예요.
- 첫 구현에서는 증강 출력을 전체 가치에 섞었어요. 그 결과 레오나 + 핀볼 몰빵이 풀 주문력이 되고, 사이온 + 강타자는 **균형**까지 딜 빌드가 됐어요. 원칙(균형 훼손 금지) 위반이라 위 구조로 고쳤어요.

## 3. 균형·몰빵 목표 함수 (P3)

| | 균형 | 몰빵 (V0 기본) | 몰빵 (실험: 공식 뺌·δ) |
|---|---|---|---|
| 전체 전투 가치 | 챔피언 성향 | 챔피언 성향 | 챔피언 성향 |
| 증강 몫 | 없음 (전투 가치 안에 포함) | + 증강 출력 가중치로 1배 | δ: **증강 몫 최대**, 단 전투 가치 ≥ (1 − δ) × 균형 |
| 공식 추천 가산 | 있음 | 있음 | **없음** |

- **공식 가산 실험(V1)**
  - 목표 함수 왜곡 655 → 10, 둘 다 나은 빌드 놓침 657 → 10이에요.
  - 몰빵 전투 가치는 오히려 균형보다 6% 높아요.
- **균형 빌드 검증(P3-1)**: V1에서 몰빵의 전투 가치가 균형보다 높아요(전사·탱커 1.11, 서포터 1.09).
  - 균형 빌드도 공식 가산점 때문에 수치상 더 나은 조합을 놓친다는 뜻이에요.
  - 균형의 공식 가산은 이번에 바꾸지 않았어요(결정 필요).
- **δ 비교** (몰빵 전투 가치 / 증강 몫, 역할별 중앙값)

| 역할 | δ 0.1 | δ 0.2 | δ 0.3 |

| 원딜 | 0.94 / 1.08 | 0.86 / 1.17 | 0.78 / 1.26 |
| 메이지 | 0.98 / 1.44 | 0.88 / 1.50 | 0.79 / 1.53 |
| 탱커 | 0.93 / 1.91 | 0.84 / 2.02 | 0.77 / 2.51 |
| 전사 | 1.00 / 1.98 | 0.98 / 2.36 | 0.98 / 2.43 |

- δ 없이(V0·V1)는 몰빵이 균형의 80% 아래로 떨어지는 장면이 37~41개 있어요(표본 608). δ를 걸면 0이에요.

## 4. 탐색 알고리즘 (P4)

- **최종 점수를 순서 무관하게**: 태그 감쇠를 태그 점수 큰 순서로 계산해요(같은 구성 = 같은 점수, 테스트).
- **빔 뒤 한 칸 교체 탐색**
  - 같은 목표 함수, 같은 제약으로 해요(같은 계열·신발 1개·필수·고정·균형 코어 칸 수). 신발도 교체해요. 최대 3번 되풀이해요.
  - 원인이었던 S1(한 칸 앞 점수로 자름)·S2(상한 있는 효과를 일찍 고정)를 직접 다뤄요.
- **결과**
  - 탐색 실패 275 → **3**(V0)이에요.
  - 레오나 + 핀볼: 지크의 융합 → 워모그·란두인, 전투 가치 1.25 → 1.86
- **두 칸 이상 조합(P4-2)**: 한 칸 교체를 되풀이하면 여러 칸이 바뀌어요(V0에서 남은 3건). δ 모드의 37~61건은 제약형 목표에서 한 칸씩으로는 못 넘는 경우예요. δ를 정한 뒤 필요하면 두 칸 교체를 더해요.
- **계산 시간** (`tools/perf_check.js`, 처음 계산)

| 장면 | 이전 | 이후 |
|---|---|---|
| 빌드 3종 | 282ms | 440ms |
| 증강 선택 등급 | 54ms | 77ms |
| 다음 구매 | 3.5ms | 4.1ms |

  - 같은 입력을 다시 계산하면 기억된 값을 써서 0.06ms 그대로예요.
  - 윈도우·맥 실기기 시간은 아직 측정하지 않았어요.
