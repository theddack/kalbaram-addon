## 1. 무엇을 어떻게 봤나

추천 대상 아이템 **114개**(전설 107 · 신발 7, 증강 보상 4개는 자동 추천을 안 해서 뺐어요)마다:

1. **원본 설명**(`desc`·`passiveHtml`)을 기본 능력치 머리글과 고유·사용 효과 문단으로 나눈다
2. 문단에서 **숫자를 전부 뽑는다** — 수치 · 비율 · 계수 · 지속시간 · 재사용 대기시간 · 중첩·횟수
3. 구현 쪽 숫자를 전부 모은다 — `stats` · `passiveStats` · `effects` · `rules.items`
4. 숫자끼리 맞춰 보고, **못 맞춘 숫자**마다 그게 왜 없는지 사람이 판단한다
5. 효과 키가 엔진 어디에서 읽히는지(**계산 경로**)를 찾아 함께 적는다

도구는 `tools/p5a_item_audit.js` 로 새로 만들었고, 표는 패치마다 `--write` 로 다시 만들 수 있어요.

**원본 설명에 수치가 없을 때**는 `passiveHtml` → `modeValues` → 아이템 `refs` 의 위키 순서로 찾았어요.

> **'원본 근거 부족'과 '현재 모델 범위 밖'을 가르는 기준** (2026-11-26 정리): 막는 것이 **수치**면 '원본 근거 부족', 막는 것이 **계산 칸**이면 '현재 모델 범위 밖'이에요. 둘 다 걸리면 주된 쪽으로 분류하고 나머지는 비고에 적었어요.
> 이 기준으로 네 개를 옮겼어요 — 슈렐리아의 군가(수치는 있고 아군 이동 속도 칸이 없음 → 모델 범위 밖), 마법공학 총검·로켓 벨트(원본에 피해 수치가 0·없음 → 원본 근거 부족), 판금 장화(가정값 12% 로 **이미 계산되고 있음** → 부분 구현).

- **기본 능력치는 114개 모두 원본과 같아요** (설명 숫자 ↔ 계산 능력치, 어긋남 0). 강인함만 수치로 쓰지 않아요.
- **칼바람 전용 수치**가 적용된 아이템은 26개(추천 대상 25개)예요. 빌드할 때 `modeValues` 로 표시돼요.
- 효과 키 **49개 전부**가 엔진 소스에서 읽히고 있어요 — **계산에 연결되지 않은 채 데이터에만 있는 효과는 0개**예요.
- 아이템 안에서 **같은 문장을 두 번 세는 곳은 없어요.** `stats` 와 `passiveStats` 에 같은 키가 있는 3개(윤 탈 야생화살·대자연의 힘·영겁의 지팡이)는 전부 '기본 능력치 + 고유 효과로 더 붙는 몫'이라 합산이 맞아요.
- 아이템 두 개의 순서를 바꿔도 결과가 같아요 (기존 `tools/item_audit.js` 표본 1,856쌍, 순서 문제 0).
