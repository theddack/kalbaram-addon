> 위 아이템들을 추천에서 빼지는 않는다. 기본 능력치와 구현된 효과로는 그대로 올라온다 (C5 와 같은 원칙).

## 8. Phase 5 뒤에 남은 것 (2026-11-26 — 이 목록이 가장 최신이다)

Phase 5 로 **정상 구현 24 → 51 · 미구현 21 → 5 · 잘못된 구현 3 → 2** 가 됐다.
아래가 남은 전부이고, 각 줄에 **계산식 · 왜 지금 못 넣는가 · 넣으면 무엇이 달라지는가**를 적었다.
근거 없는 수치를 임의로 확정하지 않는다는 원칙에 따라 전부 보류다.

### 8.1 '내 쪽 상태' 가정이 있어야 하는 것 — 실시간 데이터는 있고 추천 계산에는 없다

게임 중에는 실제 값을 받는다(`desktop.py`: `takedowns` = 킬 + 어시스트, `stats.currentHealth`·`maxHealth`).
그런데 **추천 점수는 '18레벨 완성 빌드' 한 장면**이라 '그때 내 처치 관여가 몇이고 체력이 얼마인가'라는 입력이 없다.
고정값으로 때우지 않으려면 **추천 계산이 내 쪽 상태를 입력으로 받게** 해야 하고, 그것은 '18레벨 완성 빌드'가
무엇인지를 바꾸는 핵심 가정 변경이다.

| # | 항목 | 계산식(수치는 이미 확보) | 넣으면 달라지는 것 |
|---|---|---|---|
| 20 | **탐욕의 군화** 학살 | 모든 피해 흡혈 += 0.6% × min(10, 처치 관여) | 처치 관여가 쌓인 판에서만 오른다. 지금 추천(관여 0)에서는 0 |
| 21 | **오만** 명성 | 공격력 += 15(원거리 10) + 2(원거리 1) × 처치 관여, 지속 90초(원거리 45초) | 〃 |
| 22 | **지배자의 피갑옷** 응징 | 공격력 += 기본 공격력 × 10% × (잃은 체력 비율) | 내 체력이 깎인 상태를 가정해야 한다. 지금은 '가득 찬 체력' = 0 |
| 23 | **크라켄 학살자** 벼락 증가분 | 피해 150~200 → 최대 262.5~350, 잃은 체력 비례 | 〃 |
| 24 | **'사용 효과 = 한타 1번' 가정** (F23 의 뿌리) | 지금은 재사용 대기시간과 무관하게 전부 1회. 구원 90초 · 히드라 10~15초 · 생명선 60초가 같은 대우 | 한타 간격 가정이 필요하다. 바꾸면 구원·미카엘·솔라리가 내려가고 히드라 계열이 올라간다 |
