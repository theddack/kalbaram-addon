## 1. 아이템 고유 효과 계산 보완

아이템 검증표에서 '계산되지 않음'인 아이템을 추천 빈도(v0.1.91 몰빵 빌드 3,038장면·균형 빌드 173명)순으로 보고, 설명에 수치가 있는 것부터 넣었어요. 아이템마다 분기하지 않고 공통 계산 장치를 만들어 `rules.json`에 설명 수치만 적었어요.

**그림자불꽃은 가정 하나에 결과가 크게 흔들려요.**

- 처치까지 친다고 보면 피해의 40%가 조건 아래예요. 이 경우 균형 빌드에 그림자불꽃이 들어가는 챔피언이 15명에서 64명으로 늘어요.
- 그 대신 이미 쓰고 있는 "상대 현재 체력 평균 70%" 가정에서 계산했어요. 상대 체력이 100%에서 40%로 고르게 줄어든다고 보면 평균이 70%라 그 가정과 맞아요. 이 기본값에서는 발동이 0이에요.
- 실제 판에서 상대를 끝까지 잡는 비율을 알아야 정할 수 있어요.

  2. 아군 강화를 "기준 아군(원거리 딜러 균형 빌드)의 늘어난 피해"로 계산해 피해 지표에 넣어요.
  3. 여러 아군에게 주는 효과(솔라리·구원·소라카 R)의 아군 수를 1명에서 늘려요. 근거가 될 실게임 자료가 필요해요.

### 6-1. 목표 함수 왜곡 14장면 (구원 9장면 포함)

- 14장면 모두 바꾼 빌드가 엔진 점수의 숫자 부분 두 가지에서 다 높아요.
  - 두 가지는 전투 가치(가중치 × 지표)와 증강 몫이에요.
  - 엔진 점수를 뒤집은 건 태그 점수(× 0.4)예요.
  - 예: 룰루 + 갈라진 하늘 업그레이드에서 구원 → 공허의 지팡이로 바꾸면 숫자 부분 +0.10, 태그 점수 −0.34예요.
- 태그 점수가 구원에 유리한 이유: 태그 다섯 개(주문력·마나·스킬 가속·회복/보호막·고정 피해)를 모두 더하기 때문이에요. 회복/보호막과 고정 피해는 이제 숫자로도 계산돼요.
- **탐색 오류가 아니에요.** 엔진은 자기 점수에서 가장 높은 빌드를 골랐어요.
- **계산 오류도 아니에요.**
  - 구원 고정 피해는 다른 사용 효과 아이템과 같은 '한타 1번' 기준이에요.
  - 아이템 태그는 v0.1.91과 같아요.
- 점검 도구의 '왜곡'은 태그 점수를 빼고 판단해요. 그래서 엔진이 태그 점수로 고른 근소한 차이(엔진 점수 0.2~3%)가 이 항목에 잡혀요.
- 구원 458장면 전체에서 한 칸씩 바꿔 보면
  - 숫자로도 구원이 가장 나은 장면이 316이에요.
  - 숫자로는 다른 아이템이 나은 장면이 142이고, 그중 131장면은 태그 점수 때문에 구원이 남았어요.
  - 역할별 장면 수: 메이지 145, 서포터 307.
- **바꾸지 않았어요.** 고치려면 숫자로 계산되는 효과를 태그 점수에서 빼거나 태그 비중을 바꿔야 해요. 둘 다 목표 함수 변경이라 승인이 필요해요.

### 6-2. 그림자불꽃 '체력 40% 아래' 효과가 0인 이유

- 따로 정한 발동률이 아니에요. 이미 쓰는 가정에서 나온 값이에요.
  - 그 가정은 '기준 상대 현재 체력 평균 70%'로, 현재·잃은 체력 비례 피해와 같아요.
  - 이 가정은 '한타 동안 상대 체력이 100% → 40%로 고르게 줄어든다'는 뜻이에요. 그래서 40% 아래 조건은 정확히 0이에요.
- '대상 체력 X% 아래' 조건을 한 함수로 계산하게 바꿨어요(`Stats.targetBelowShare`). 그림자불꽃이 이 함수를 쓰고, 결과는 바뀌지 않아요. 재현 테스트도 넣었어요.
- 검토하면서 찾은 기존 문제예요. 이번 변경 전부터 있었고, 고치지 않았어요.
  - **세릴다의 원한**: '체력 50% 아래인 시간 절반' 가정은 처치까지 가는 경로(100% → 0%)예요. 같은 조건을 공통 함수로 계산하면 1/6이에요. 두 가정이 서로 어긋나요.
    - 실험으로 1/6을 넣어 봐도 '왕관의 무게+취약+치명적 리듬' 원딜의 몰빵 빌드는 그대로였어요.
  - **지옥불 난사 (증강)**: '체력 30% 아래 대상에게 치명타' 사격의 피해가 일반 사격과 함께 둘 다 전부 더해져요. 중복 계산으로 보여요.
- 어느 경로(처치 안 함 / 처치까지)로 맞출지는 기본 가정을 바꾸는 일이에요. 그래서 실게임 근거나 승인 전까지 정하지 않았어요.

### 6-3. augment_regress '몰빵 < 균형' 17 → 31명

## 7. 공통 계산·평가 구조 정리 (2026-11-15 2차)

> 새 기능은 넣지 않았어요. 모두 계산 결과끼리의 비교예요. 실제 게임에서 확인한 결과가 아니에요.
> 비교 대상: **v0.1.92** = 6장까지(`fc8ac3a`), **B** = 이번 수정 포함(기본값), **C** = B + 실험 설정 '계산되는 효과 태그 빼기'(`TAG_DEDUP=effect`, 기본값 아님).

### 7-1. 지옥불 난사 발동: 치명타 사격 중복 (오류, 고침)

- 원인: '체력 30% 아래 대상에게 치명타' 사격 피해(147)가 일반 사격 피해(84)와 함께 둘 다 전부 더해졌어요. 치명타 사격은 조건이 맞을 때 일반 사격 대신 쓰여요.
- 수정은 공통 원칙으로 했어요. 챔피언 스킬 계산과 같은 원칙이에요.
  - 같은 출처·피해 종류·발동 방식에 일반 효과가 있으면, 치명타 버전은 그 대신 쓰는 버전으로 봐요.
  - 계산: 일반 + 적용 몫 × (치명타 − 일반).
  - 적용 몫: 체력 조건이 있으면 `targetBelowShare(조건)`, 없으면 치명타 확률이에요.
  - 조건 값 30%는 원본 데이터 값(`Calc_Crit_Threshold`)에서 읽어요. 규칙 이름은 `effectCritBelow`예요.
- 기본 가정(상대 체력 100% → 40%)에서는 30% 아래가 없어 치명타 몫이 0이에요.
- 재현 테스트를 먼저 넣었어요.
- 같은 구조(치명타 버전 효과)를 가진 증강·아이템을 전부 찾아봤어요.
  - 지옥불 난사 하나뿐이에요.
  - 효과가 여러 줄인 7개(연쇄 반응·해악의 숫자 3·광대 대학·전부 다 무너뜨려·그림자 검·거대한 히드라·공허한 광휘)는 설명상 따로 들어가는 피해예요.
- 남은 점(미검증): 설명은 '10회에 걸쳐' 쏘는데 계산은 1발만 세요. 사격 횟수가 원본 데이터 값으로 없어서 정하지 않았어요.

### 7-2. 체력 조건 계산 통일 (그림자불꽃·세릴다의 원한)

- 세릴다의 원한은 '조건이 맞는 시간 절반'(0.15초)을 따로 정해 쓰고 있었어요. 이는 처치까지 가는 경로(100% → 0%)예요. 같은 한타에서 그림자불꽃(100% → 40%)과 상대 체력 가정이 달랐어요.
- 고유 효과 규칙에 `_belowAt`(조건 체력)을 두면 값 × `targetBelowShare(조건)`으로 계산하게 했어요.
  - 세릴다는 라일라이와 같은 기준(0.3초) × 1/6 = 0.05초예요.
  - 새 발동률은 없어요. 기본 가정(기준 상대 현재 체력 70%)도 그대로예요.
- 이제 대상 체력 조건은 세 곳 모두 같은 함수를 써요: 그림자불꽃(40%), 지옥불 난사(30%), 세릴다(50%).
- 추천 변화(v0.1.92 → B)
  - 세릴다 몰빵 등장 628 → 621.
  - 회귀 도구 변칙 빌드 활용도 평균 374.6 → 355.7. '왕관의 무게+취약+치명적 리듬' 원딜 변칙 빌드에서 세릴다가 빠졌어요.
    - 예: 사미라 변칙이 딜 빌드에서 라일라이·케이닉 루컨 같은 제어·탱커 빌드로 바뀌었어요.
    - 변칙은 원래 약한 쪽을 키우는 빌드라 오류로 보지 않았어요.
  - 그 밖의 지표는 v0.1.92와 같거나 ±3 안이에요.
