### Phase 2 — B1·B2 수정 ✅ 완료 (`2e66167` B1 · `0d460a8` B2 · 결과: `docs/v0.1.95_Phase2_수정결과.md`)

> 계획과 다르게 한 것 하나: B1 의 스킬 쪽 키에서 **`APtoCRIT` 는 뺐다.** 이 키는 `MULT_TAG` 에서 입력 능력치(`AP`)로 가고 `CRIT` 을 만들지 않아,
> 치명타 칸 배분에 영향을 주지 않는다. 주문력으로 얻는 치명타 확률은 스킬이 아니라 평타에 붙는 것이라 평타 쪽이 맞기도 하다.
> 임계값(B2 4단계)은 계획대로 **손대지 않았다** — '얼마나 커야 여는가'가 아니라 '무엇을 근거로 여는가'만 바꿨다.

**B1 — 스킬 치명타와 평타 치명타의 평가 방향 분리**

- 손댈 곳: `web/scoring.js` 의 `MULT_TAG`·`metricWeights` 로 가는 경로. 챔피언·아이템 이름 분기는 쓰지 않는다.
- 스킬 쪽 키(`skillCritDmg`·`effectCritDmg`·`ultCritDmg`·`APtoCRIT`)는 `combo` 쪽,
  평타 쪽(`critStackAS`·`onhitOnCrit`·`AStoCRITDMG`)과 치명타 확률 자체는 `dps` 쪽.
- **아이템 태그 점수의 `CRIT` 은 건드리지 않는다** — 치명타 아이템을 찾는 기능은 유지해야 한다.
- 근거: 수치 계산은 이미 맞다(공격력 몫 0.0% / 치명타 몫 23.4%). 고치는 것은 **같은 효과를 두 칸에서 세는 중복**이다.

**B2 — 반대 유형 차단이 통째로 꺼지지 않게 (지적 3 반영)**

- 손댈 곳: `web/scoring.js` `offTypeFilter` 의 `flips` 판정.
- 네 단계:
  1. `convert`(실제 유형 전환)가 있으면 지금처럼 **전체 해제** — 적응형 능력치·마법사(물리)의 비정석 빌드를 지킨다.
  2. `convert` 가 없으면 **lift 가 가리키는 태그를 가진 아이템만** 연다 (전술적 대비 → 주문력 아이템, 보석 건틀릿 → 치명타 아이템).
  3. **아이템 하나 안에서도 능력치·고유 효과별로 활용도를 구분한다.** 무한의 대검(AD 75 + CRIT 25% + CRITDMG 30%)처럼
     섞인 아이템은 "증강이 살리는 능력치를 가졌는가" 로 차단 여부를 정하고, 못 쓰는 능력치 몫은 **수치 계산이 0으로 만든다**
     (아리 + 보석 건틀릿에서 공격력 몫은 이미 콤보 +0.0%). 일부 능력치가 반대 유형이라는 이유로 연계 효과까지 막지 않는다.
  4. 임계값(지금은 lift 차이 0.2 로도 해제)은 `증강_가중치_연결표.md` 3장 분포를 근거로 제안하고 **승인 뒤에 바꾼다.**
- 절대 하지 않을 것: 챔피언 id·아이템 이름 목록 예외 처리.

## 6. 아직 확인하지 못한 것

- 아리 2판의 네 번째 증강은 기록에 `null`(이름을 못 읽음)이다. 치명타 계열이었다면 B1 영향이 더 컸을 수 있다.
- 독사의 송곳니 보호막 감소율, 강인함의 중첩·상한 방식은 원본에서 확인하지 못했다.
- `flips` 임계값(얼마를 '뚜렷한 차이' 로 볼지)은 아직 정하지 않았다 — Phase 2 에서 분포를 근거로 제안하고 승인받는다.
- Phase 4 의 "피해량 손실" 축이 `buyNowGains` 로 충분한지는 구현해 봐야 안다.
- 이 문서의 모든 수치는 기록된 스냅샷·이벤트와 전체 데이터를 코드에 그대로 넣어 재현한 값이다. 실제 게임 재현은 하지 않았다.

**Phase 1 은 조사·도구·테스트뿐이고 추천 계산식은 한 줄도 고치지 않았다. Phase 2 이후는 승인 뒤에 시작한다.**
