## 1. 아이템으로 못 키우는 증강의 몰빵 → 균형 빌드 재사용

**문제 확인** (V1, 3,038장면)

| 안내 | 몰빵 = 균형 | 다름·증강 몫 이득 없음 | 다름·증강 몫 늘림 |
|---|---:|---:|---:|
| 효과 없음 | 30 | 72 | 39 |
| 고정 효과 | 384 | 463 | **626** |
| 아이템과 무관 | 30 | 32 | **44** |
| 수치 계산되는 증강 | 256 | 240 | 822 |

- 안내 종류로 일괄 빼면 간접 연계 670장면(고정·아이템과 무관인데 아이템으로 커짐)까지 잃어요. 예: 베인 + 빵과 버터·처형 시간
- 그래서 **실제 증강 몫으로** 판단해요.

**규칙** (`web/scoring.js`) — 몰빵이 균형 빌드(같은 증강)보다 아래 둘 중 하나면 균형 빌드를 그대로 써요.
1. 증강 몫을 0.02%p 이상 못 늘림
   - 0.02는 점검표 '아이템 무관' 기준과 같아요.
2. 증강 몫 증가율 < 전체 전투 가치 증가율
   - 비율끼리 비교라 새로 정한 기준값이 없어요.
   - 바뀐 이유가 증강이 아니라 공식 추천을 뺀 전투 가치 계산 최적(전사 풀탱·서포터 딜)일 때예요.
- **예외**: 꼭 넣을 아이템이 있는 증강(퀘스트·업그레이드·효과 종류 증강 중 키울 능력치가 있는 것)

**결과**

| 사례 | 몰빵 |
|---|---|
| 가렌 + 사악한 정신 / 레오나 + 핀볼 | 균형 그대로 (V1에선 풀탱) |
| 소라카 + 원기 회복 | 균형 (증강 몫 +3% · 전투 가치 +24% → 딜이었음) |
| 사이온 + 강타자 | 균형 (+2% · +9%) |
| 나미 + 흡수 | 주문력 빌드 유지 (+199% · +104%) |
| 럭스 + 마법 명사수 | 유지 (+40% · +6%) |
| 제드 + 치명적 리듬 | 유지 (증강 몫 125 → 513) |
| 베인 + 빵과 버터·처형 시간 | 유지 (간접 연계) |

- 재현 테스트: `tests/recommend.test.js` "몰빵: 아이템으로 증강을 못 키우면 …"

**소라카·룰루 악화의 원인**
- 이번 수정 때문이 아니에요. P4 교체 탐색 때부터예요.
- 같은 목표 함수에서 월석(소라카)·헬리아(룰루)가 지금 빌드보다 **0.2% 낮은 거의 동점**이에요.
- v0.1.90은 빔 탐색 순서 덕에 들어가 있었어요.
- 근본 원인은 전투 가치 계산에서 서포터 몫이 피해보다 작게 잡히는 것이에요.
  - 아군 버프 몫 미계산
  - 한타 피해 기준값(300)이 작음
- 이건 가중치·척도 결정 사항이라 손대지 않았어요.

**유미**: 불타는 향로의 아군 공격 속도 몫이 계산에 없어서예요(같은 원인).

**증강 몰빵**
- 원기 회복: 레나타·잔나·나미·룰루가 지원 아이템 포함으로 개선
- 흡수: 서포터 대부분이 주문력 빌드
  - 스킬 피해 → 회복이라 증강 몫이 크게 늘어요.
  - 증강 중심 원칙대로예요. 균형 빌드는 그대로예요.

## 6. 위험 사례

1. **적중 증강 몰빵의 구인수 급증** (8~12 → 67~70장면)
   - 평타 100% 가동 가정에 기대요. 0.5면 11~21로 줄어요.
   - 근접 전사 + 강타자·화염 낙인·전부 다 무너뜨려에서 실게임 확인이 필요해요.

   - 동점 근처, 서포터 몫 척도 문제

   - 그나르가 탱커 아이템 위주, 사이온·레오나 구성 교체
