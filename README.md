# 칼바람 증강 Addon

> **어떤 증강도 재밌게.** 서포터가 원딜처럼, 탱커가 근접 딜러처럼 — 고른 증강에 맞춰 다음 증강과 아이템을 안내하는 칼바람 증강 모드(아수라장) 도우미예요.

**[⬇️ 프로그램 받기 (윈도우·맥)](https://github.com/theddack/kalbaram-addon/releases/latest)** · [✅ 받은 파일 확인](https://theddack.github.io/kalbaram-addon/verify.html) · **[🌐 웹에서 바로 보기](https://theddack.github.io/kalbaram-addon/)** · [📖 사용 설명서](사용설명서.md) · [📝 업데이트 내역](업데이트내역.md) · [🔗 데이터 출처](https://theddack.github.io/kalbaram-addon/sources.html)

![칼바람 증강 Addon 화면](docs/screenshot.png)

## 이런 걸 해요

| 기능 | 설명 |
|---|---|
| **첫 증강 추천** | 챔피언 스킬·능력치로 증강을 🔥강력 추천 ~ 🎲도전까지 나눠요 |
| **다음 증강 = 연계 순서** | 첫 증강을 고르면 그 증강과 잘 맞는 순서로 다시 나눠요. 등급과 따로 🔗 강한 연계 · ➕ 일반 연계 · ➖ 직접 연계 없음 · ⚠️ 효과 충돌 · ❔ 판정 불확실을 보여 줘요 (고른 증강 전부 누적). 🔄 변신(서포터 → 원딜형 등)도 알려 줘요 |
| **이번 선택지 비교** | 게임에 뜬 증강 3개를 넣으면 무엇이 얼마나 강해지는지, 새로고침할 칸은 어디인지 알려 줘요. 🎮 고르면 어떻게 싸우고 뭘 같이 사는지, 🎉 재미 픽(가장 강하진 않아도 플레이가 확 바뀌는 선택), 🎭 변칙 열쇠도 표시해요 |
| **다음에 살 아이템** | 고른 증강과 연계되는 아이템 순서. 라이엇이 챔피언마다 정한 칼바람 추천 아이템은 가산점으로 더해요. 추천 빌드는 증강 몰빵 · 균형 · 변칙 3가지. 변칙은 반대쪽을 키우는 증강이 있을 때만 그만큼 뒤집고, 없으면 🧪 실험 빌드라고 알려 줘요 |
| **게임 연동** (프로그램) | 챔피언·레벨·산 아이템 자동 반영, **💰 지금 골드로 살 부품**, 게임 화면 위 표시(증강 고를 땐 카드 평가만, 상점 열 때 상세, 죽었을 땐 다음 구매·지금 살 것만)(창 모드·테두리 없음), 상점 추천 칸 등록, **🔍 Tab 점수판으로 적 증강 읽기**(시험, 설정에서 켜기), **⏳ 증강 쿨타임**(퀸카·신성한 중재·감시의 장막·도주 계획·빛의 인도자 결의, 고른 시각·내 체력으로 짐작한 예상값) |
| **📏 내 실측** (프로그램) | 게임이 끝나면 경기 결과와 전적(10명이 고른 증강·아이템·승패)을 저장해 가정값·점수판 읽기와 비교 (이름·계정은 지우고 내 PC에만) |
| **매일 새 데이터** | 게임 데이터·위키·공식 패치 노트를 매일 받아요. 새 증강은 ✨, 이번 패치 변경은 🆕 표시. 패치 노트 숫자는 게임 데이터와 줄마다 맞춰 봐요 |
| **📐 근거 보기** | 숫자마다 게임 데이터인지, 설명 수치인지, 정한 값(⚠️ 가정)인지와 **그렇게 정한 이유**를 보여 줘요 |
| **쉽게 보기** | 처음엔 추천·이유·살 아이템만. 능력치 표·점수는 '자세히 보기'에서 |

숫자는 승률 통계가 아니라 **게임 데이터 수치로 계산**해요 (스킬 한 바퀴 피해, 초당 피해, 버티는 힘, 회복·보호막, 기동성, 제어력). 통계 사이트는 링크만 걸어요.

## 3단계로 시작

1. [릴리스](https://github.com/theddack/kalbaram-addon/releases/latest)에서 `KalbaramAddon-Windows.zip`(또는 Mac)을 받아요. 압축을 풀기 전에 **[받은 파일 확인](https://theddack.github.io/kalbaram-addon/verify.html)**에 끌어다 놓아 ✅인지 보고, 압축을 풀고 실행해요.
2. 롤 설정 → 비디오 → 창 모드를 **테두리 없음**으로 바꿔요.
3. 프로그램에서 **게임 연동**과 **게임 화면 표시**를 켜고 게임을 시작해요.

처음 실행 시 경고가 뜨면 [사용 설명서](사용설명서.md#처음-실행할-때-경고가-뜨면)를 보세요. 맥에서 "손상되었다"고 나오면 v0.1.3 이하 파일이에요. 최신 버전을 받으세요.

문제가 생기면 [GitHub 이슈](https://github.com/theddack/kalbaram-addon/issues)에 증강 선택 화면 스크린샷과 기록 파일을 올려 주세요.
기록 파일 위치: 윈도우 프로그램 폴더 안 `data\logs\` · 맥 `~/Library/Application Support/AramAugment/logs/` — [자세히](사용설명서.md#기록-파일-위치)

## 정확도와 한계

**정확한 지표가 곧 재미**라서, 무엇을 계산하고 무엇을 못 하는지 그대로 적어요 (패치 16.20 기준).

| 항목 | 현재 |
|---|---|
| 숫자로 평가되는 증강 | **155 / 215개**. 나머지 60개 중 24개는 퀘스트·무작위·소환사 주문이라 종류로 표시하고, 36개는 특정 스킬·아이템에만 붙는 효과라 효과 종류로만 판단해요 |
| 숫자로 평가되는 아이템 고유 효과 | **62 / 118개** |
| 챔피언 패시브 | 96명이 계산에 들어가요 (중첩형 9명은 게임 중반 평균 중첩으로: 베이가·쓰레쉬·세나·초가스·사이온·스웨인·킨드레드·나서스·스몰더). 변신형 패시브는 아직이에요 |
| 스킬 수치 | 692개 스킬 중 **25곳**을 못 채웠어요 (게임 중 계산값 등). 능력치끼리 곱하는 식(닐라 Q 등)도 실제 능력치로 계산해요. 소환물 피해는 콤보에 안 들어가요. 최소~최대는 최대, 대체 버전(강화·카드)은 하나만 세요 |
| 상대 체력 % 피해 | 스킬 25명 + 증강·아이템·패시브가 계산에 들어가요. 상대 현재 체력은 70%로 가정해요 |
| 상대 | 기본은 전 챔피언 173명의 18레벨 추천 빌드 **중앙값**(체력 3148·방어력 113·마법 저항력 63). 게임 중엔 **이번 판 적이 실제로 산 아이템**으로 잡아요: 아이템·증강 비교는 18레벨 완성 기준이라 '산 아이템 + 안 산 칸은 평균 빌드'로, 능력치 패널의 지금 수치는 '적의 지금 레벨 + 산 아이템만'으로. 관통·치유 감소 조언은 적이 실제로 산 아이템만 보고 해요 (방어 아이템 3개 이상, 흡혈 아이템). '상대'에서 챔피언을 고르면 그 챔피언 기준으로 계산해요 |
| 콤보 | Q·W·E·R 각 1번, 4초 기준이에요. 여러 번 맞히는 스킬과 지속 피해는 1번분만 세요 |
| 발동 빈도 | 설명 문구로 판정한 근사값이에요 (충전 공격은 기본 공격 8번에 1번). 게임 데이터에 몇 번째 공격인지 숫자가 있으면 그걸 써요 (크라켄 학살자: 3번째, 기본 피해 — 최대값 아님) |
| 칼바람 보정 | 위키 표(일반 칼바람 + 증강 모드 전용 59명)를 써요. 위키 표의 기준 시점이 25.17이라 최신 패치와 다를 수 있어요 |
| 효과 분류 | 모든 증강이 효과 종류나 종류 표시(📜 퀘스트 · 🎰 무작위 · ✨ 소환사 주문)를 가져요 |
| 수치 일부 `?` | 16개 증강. 대부분 퀘스트 목표·게임 중 누적값이라 원래 숫자가 없어요 |
| 가정값 | 게임에 숫자가 없는 값(가동률·평균 중첩 등) 증강 36개·아이템 14개 + 공통 12개는 모두 **이유와 함께** 📐 근거·[계산 가정값](https://theddack.github.io/kalbaram-addon/sources.html#assumptions)에 적었어요. 실측이 아니라서 게임 기록이 모이면 바꿀 거예요 |
| 특수 규칙 | 증강 144개의 규칙(`rules.json`)은 설명을 읽고 사람이 판단한 것이고, 새 증강은 설명에서 🤖 자동 추정해요. 둘 다 실제 게임에서 검증하지 않았어요 |
| 챔피언 전투 특성 | 게임 계산식에 빠진 스킬 효과(베인 은화살, 바루스 역병 폭발, 진 4번째 탄, 징크스 미니건 공격 속도)와 케일 18레벨 사거리를 스킬 설명 수치로 넣었어요. 몇 번 터지는지·얼마나 유지하는지는 가정이라 📐 근거에 적었고, 추천 점수에만 쓰고 게임 중 지금 능력치 비교에는 넣지 않아요. 실제 게임에서 검증하지 않았어요 |
| 패치 노트 | 줄마다 게임 데이터와 대조해요 (16.20: 30줄 중 ✅ 27 · 대조 불가 2 · 데이터에서 못 찾음 1). 게임 데이터가 늦으면 확실한 줄만 패치 노트 값으로 임시 계산해요 |
| 추천 결과 | 롤 클라이언트 전적으로 처음 대조했어요 (내 칼바람 증강 모드 39판, 플레이어 336명, `tools/match_check.js`). 사람들이 실제로 고른 증강은 우리 S·A 등급이 44%예요 (아무렇게나 고르면 30%), D는 6.6% (15%). 하지만 고른 증강의 우리 등급과 승률은 차이가 없었어요 (상위 절반 49.7% · 하위 절반 50.3%). 산 전설 아이템이 우리 증강 몰빵 빌드와 겹친 수는 이긴 쪽 1.41 · 진 쪽 1.11개예요. 표본이 작아 승률로 추천을 고치지는 않아요. 점수가 5% 안으로 비슷할 때 근거(증강 필요 → 연계 → 라이엇 추천) 순으로 바꾸는 규칙은 같은 전적에서 실제로 산 아이템이 Top3 에 드는 수를 0.73 → 0.76개로 늘렸어요 (`tools/tie_check.js`, 262명) |
| 적 증강 | 게임 연동으로는 소환사 주문 칸 증강(9개)만 보여요. Tab 점수판 아이콘으로 나머지를 읽는 기능은 시험 중이라 **기본 꺼짐**이고, 켜도 정보로만 보여 주고 아이템 대응에는 쓰지 않아요. 첫 실제 판에서 적 증강 3개 중 1개만 맞았어요 (아군 줄을 적으로 착각). 판이 끝나면 전적의 정답과 맞춰 진단 기록에 남겨요 |
| 추천 품질 점검 | 계산끼리의 일관성 검사예요, 실제 게임 정확도가 아니에요(`node tools/augment_quality.js`, 대표 챔피언 12명 × 증강 전부). 몰빵 빌드가 증강을 살리는 비율 98.2% (2,009개 중 1,972), 변칙 100% (79개). 라이엇 공식 칼바람 추천 아이템은 가산점으로만 써요 (`node tools/official_check.js`: 공식 핵심을 담는 챔피언 108명 중 19 → 81명, 서로 다른 6칸 구성 49 → 77가지). 공식 추천이 없는 54명은 성향이 비슷한 챔피언 3명의 공식 추천을 빌려요 (자기 공식 추천을 가리고 채점하면 공식 핵심 담기 58명). 계산을 고칠 때마다 모든 챔피언·대표 증강·기록한 판의 추천을 기준선과 비교해요 (`node tools/rec_baseline.js`). 실패 원인 분류는 [추천 품질 점검](docs/추천_품질_점검.md), 증강별 쓰는 법 문장은 [쓰는 법 목록](docs/쓰는법_목록.md) |

미검증: 윈도우 실제 PC에서의 게임 화면 표시(창 찾기·클릭 통과·화면 배율), 게임 연동 실데이터(지금 골드 포함), 상점 추천 등록, Tab 점수판 적 증강 읽기(첫 실제 판 3개 중 1개 맞음 → 기본 꺼짐), 판 끝 전적 대조, 게임 화면 상태별 표시(증강 선택 중 카드만 · 죽음엔 한 줄 · 상자 자리).

테스트: 화면·계산 107개(`npm test`) + 파이썬 110개(`python -m unittest discover -s tests`). 빌드·사이트 배포·매일 갱신이 모두 테스트를 먼저 돌려요.
